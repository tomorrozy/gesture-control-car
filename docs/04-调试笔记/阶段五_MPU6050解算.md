## 一、排查总顺序

```text
① I2C 通不通：读 WHO_AM_I(0x75) 是否 0x68
② 原始值对不对：平放某轴应接近 2048
③ 角度对不对：倾 90° 输出是否接近 90
④ 稳不稳：静止看漂移、晃动看抖动
⑤ 周期对不对：用 Time_ms 打点实测
```

> [!info] 三个速查点
> ① 全 0/全 FF 查供电与上拉；② 数据跳查电源与地；③ 角度漂查校准。

## 二、【现象】→【可能原因】→【排查步骤】→【修正与防范】

| 现象 | 可能原因 | 排查步骤 | 修正与防范 |
|---|---|---|---|
| 读不到数据（全 0/全 FF） | 未供电 / SCL·SDA 接反 / 无上拉 / 地址错（AD0） | 万用表量 VCC；示波器看 SCL 有无时钟；读 `WHO_AM_I` | 供电/换线/加上拉/改地址 |
| 数据剧烈跳变 | 无滤波 / 电源噪声 / 地线长 | 示波器看 3.3 V 纹波 | 加电容、共地、缩短线 |
| 静止时一直漂 | 零偏未校准 / 校准时在动 | 重上电静止校准；看 offset | 静止校准；加静止检测 |
| 跟手但发抖 | α 偏小（太信加速度） | 改 α=0.99 对比 | 调 α |
| 平滑但漂 | α 偏大（太信陀螺） | 改 α=0.8 对比 | 折中或加校准 |
| 大角度爆掉 | `tanf(pitch)` 在 ±90° 发散 | 倾到接近 90° 观察 | 限制使用范围/改用四元数 |
| 屏幕有角度但车不动 | 主程序没把角度传给发送 | 查 `main.c:134–144` | 接上链路 |
| 数值整体差几倍 | 量程常量与寄存器不匹配 | 核对 16.4/2048 与 0x18/0x18 | 成对修改 |

## 三、工具怎么用

| 工具 | 测什么 | 正常值 |
|---|---|---|
| 万用表 | VCC / SCL·SDA 空闲 | 3.3 V / 约 3.3 V（上拉） |
| 示波器 | SCL（`GPIOB` Pin6） | 成串时钟，空闲高 |
| 示波器 | SDA（`GPIOB` Pin7） | 起始时 SCL 高期间出现下降沿 |
| 调试器 | `pitch/roll/acc_pitch/gx_deg` | 静止 gx_deg≈0；倾 90° acc_pitch≈90 |

## 四、本阶段 4 个必踩坑

> [!warning] 坑 1 · 忘记上拉
> 开漏输出无上拉 → 读不到高电平，表现为“完全读不到”。模块板载上拉要确认。

> [!warning] 坑 2 · 校准时动了
> `CalibrateGyro` 取平均当零偏（`MPU6050.c:82–83`）；校准时动 → 零偏错 → 永久漂。

> [!warning] 坑 3 · `LOOP_TIME` 与实际周期不符
> 代码写 `0.01f`（`MPU6050.c:13`），但主循环还有两次 I2C 读 + 整屏刷新；周期不对滤波失真。

> [!warning] 坑 4 · 双次校准白做
> `main.c:105/106` 连调两次，第二次覆盖第一次；第一次 200 次基本是浪费。

## 五、10 分钟定位法

1. 万用表量 VCC、SCL/SDA 空闲电平。
2. 读 `WHO_AM_I`（0x75），应为 0x68（AD0 接地）。
3. 平放看某轴是否约 2048（±16 g）。
4. 倾 90°，看 `acc_pitch/acc_roll`。
5. 静止看漂移、晃动看抖动。
6. 用 `Time_ms` 打点算出真实周期，判断 `LOOP_TIME` 该填多少。
