## 怎么读（两条路线）

### 路线 A：零基础，目标是把车做出来

```
03-零基础落地包/  →  01-八阶段教程/  →  02-图解字典/  →  04-调试笔记/
   器材、工具链         每阶段怎么实现        概念看不懂查这里      卡住了查这里
```

1. 先看 [`03-零基础落地包/`](03-零基础落地包/)：买什么、装什么、怎么供电上电
2. 按 [`01-八阶段教程/`](01-八阶段教程/) 从阶段一做到阶段八，每阶段做完对照
   [`03-零基础落地包/04-八阶段逐阶段操作与验收门禁.md`](03-零基础落地包/04-八阶段逐阶段操作与验收门禁.md) 验收
3. 遇到不懂的名词查 [`02-图解字典/`](02-图解字典/)
4. 出 bug 先翻 [`04-调试笔记/`](04-调试笔记/)

### 路线 B：有嵌入式基础，只想看实现

```
00-学习路线与工程全景  →  01-八阶段教程  →  05-参考资料
```

先看 [`00-学习路线与工程全景.md`](00-学习路线与工程全景.md) 建立整体架构，再按需查具体阶段。
