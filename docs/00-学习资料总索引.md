## 三、基准事实（全库统一，已逐行核对）

| 项目 | 事实 | 出处 |
|---|---|---|
| MCU / 主频 | STM32F103C8T6 ×2；72 MHz（HSE 8 MHz × `PLLMULL9`） | `system_stm32f10x.c`、`stm32f10x.h` |
| 协议 | 13 字节：`A5 / 09 / pitch4 / roll4 / gesture1 / XOR / 0D` | 两端 `main.c` |
| 无线 | nRF24L01，`RF_CH=40`（2440 MHz）、2 Mbps、32 字节定长 | `nRF24L01_API.c` |
| 控制周期 | 20 ms（`configTICK_RATE_HZ=1000`） | `main.c:303`、`FreeRTOSConfig.h:97` |
| 发送节拍 | 100 ms（≈10 Hz） | `遥控 main.c:156` |
| 编码器 | 常数 `52` → 反推 **13 线**（4×13）；减速比 **1:13** → 676 计数/输出圈 | `main.c:265`、你的确认 |
| PID | 位置式 PI：Kp=2.0、Ki=1.5、Kd=0（D 未实现） | `main.c:84/166` |
| 时延 | 100 + 20 + 20 ≈ **140 ms** | `main.c:206/303` |

## 四、硬伤清单（审查后刷新）

| # | 硬伤 | 位置 | 后果 | 修法 |
|:--:|---|---|---|---|
| 1 | **失联不停车** | `task_rx` 无超时 | 遥控断电后车继续跑 | 记最后收包 tick，超 300 ms 目标清零 |
| 2 | **无 VOFA 打印** | 全工程裸 `printf` = 0 | 闭环无法量化 | 用阶段七 3.10 的打印，调参时开 |
| 3 | **差速无归一化** | `main.c:256–259` 各自截断 | 大角度斜推比例失真（5.5:1→3.25:1） | 等比缩放（阶段八 3.8） |
| 4 | **反馈系数 9.27666** | `main.c:265–266` | 与 1:13 不符 → 反馈高估约 40% | 改 `13.0f` 后重调 Ki（前提：线数=13） |
| 5 | **三套左右开关** | 遥控 `Gesture_Map:66` 互换后门 + 小车 `REVERSE_TURN` + 遥控 `×-1.0f` | 同时改会互相抵消，方向排查困难 | 只保留一个入口，其余置默认 |
| 6 | **三套阈值** | 遥控 15/15、控制 10/15、显示 10/15 | `pitch=12°` 时屏幕说停、车却走 30% | 统一常量，或把阈值集中到一个头文件 |

**死代码/死变量（答辩会被问）**：`g_gesture` 只写不读（96/202）；`MIN_SPEED` 未使用（221）；`channel` 未使用（97）；`cos_pitch` 算了不用（MPU6050.c:120）；`kd`/`prev_err` 未参与公式（85）。

## 五、待补信息（我仍未掌握，不猜）

| 项 | 需要什么 | 影响 |
|:--:|---|---|
| TB6612 实物接线 | PWMA/PWMB/AIN1/AIN2/BIN1/BIN2/STBY 各接哪 | “前进”是否与代码一致 |
| 嘉立创工程 | BOM（CSV）+ 原理图 PDF | `.eprj2` 当前只剩空 `attributes` 表，读不出元件/网络 |
| 编码器线数 | 是否 13 线 | 决定 52/676 与 40% 修正是否成立 |
| 电机额定转速 | 铭牌参数 | 决定 0~100 对应多少 cm/s |
| 物理方向 | 前进/左转是否与逻辑一致 | 需上车实测（`REVERSE_TURN`/取反/接线三者耦合） |
| `LOOP_TIME` | 主循环实测周期 | 阶段五互补滤波的 `0.01f` 是假设 |
