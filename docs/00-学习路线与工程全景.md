## 一、这是一个什么工程：一句话 + 两张角色卡

**一句话**：两块 STM32F103C8T6 组成的"手势遥控车"——
**手带端（`遥控\`）戴在手上**，用 MPU6050 测出俯仰角/横滚角，打包成 13 字节的无线帧发出去；
**小车端（`FreeRTOS小车\`）装车上**，收到帧后把角度换算成左右轮目标速度，用编码器做速度闭环 PID，驱动两个电机差速转向。

```
        手带端（遥控工程）                          小车端（FreeRTOS小车工程）
  ┌──────────────────────────┐             ┌──────────────────────────────┐
  │ MPU6050 ──软件I2C──┐     │             │  nRF24L01 ──软件SPI──┐         │
  │                    ↓     │  2.4GHz     │                      ↓         │
  │              互补滤波     │  13字节帧   │  解包 → pitch/roll            │
  │                    ↓     │ ──────────► │           ↓                   │
  │           手势映射 Gesture│             │   姿态→左右轮目标速度          │
  │                    ↓     │             │           ↓                   │
  │       打包 0xA5…0x0D      │             │   PID 闭环（编码器反馈）        │
  │                    ↓     │             │           ↓                   │
  │  OLED（给人看）  nRF发送   │             │  PWM → TB6612 → 电机 → 编码器  │
  └──────────────────────────┘             └──────────────────────────────┘
```

### 角色卡 A：手带端 `遥控\`

| 项目 | 实测值 |
|---|---|
| Keil 工程文件 | `Template.uvprojx` |
| 芯片 / 容量宏 | `STM32F103C8` / `STM32F10X_MD`（64 KB Flash、20 KB RAM） |
| 启动文件 | `Libraries\CMSIS\startup_stm32f10x_md.s` |
| **有没有操作系统** | **没有**。裸机：`main()` 里一个 `while(1)`，加一个 1 ms 定时器中断 |
| 时间基准 | `TIM4` 1 ms 中断（`Public\time4.c`），中断里给 `Time_ms` 加 1 并扫描按键 |
| 主循环节拍 | 循环显示 OLED；`Time_ms > 100` 时打包并发送一帧 → **约 10 Hz** |
| 无线 | nRF24L01，**软件 SPI**，引脚 `PA0~PA5`（CSN/CE/SCK/MOSI/MISO/IRQ） |
| 显示 | OLED SSD1306，**软件 I2C**，`SCL=PB8`、`SDA=PB9` |
| 姿态传感器 | MPU6050，**软件 I2C**，`SCL=PB6`、`SDA=PB7` |
| 人机输入 | 5 个按键：`PB12/PB13/PB14/PB15/PA8`（上拉输入，按下为低） |
| 指示灯 | `PC13`（LED0）、`PA7`（LED8） |

### 角色卡 B：小车端 `FreeRTOS小车\`

| 项目 | 实测值 |
|---|---|
| Keil 工程文件 | `USER\FreeRTOS.uvprojx` |
| 芯片 / 容量宏 | `STM32F103C8` / `STM32F10X_MD`（同左） |
| 启动文件 | `CORE\startup_stm32f10x_hd.s` ⚠️ **hd（大容量）启动文件 + MD 容量宏 = 不自洽，第 1 章专门核对** |
| **有没有操作系统** | **有**。FreeRTOS，4 个任务（start/rx/ctrl/disp），**全部静态创建**（不 malloc） |
| 任务节拍 | `task_rx` 20 ms 收一次包、`task_ctrl` 20 ms 跑一次 PID、`task_disp` 50 ms 刷一次屏 |
| 无线 | nRF24L01，软件 SPI，引脚 `PA2~PA5` + `PB0/PB1`（CSN/CE/SCK/MOSI + MISO/IRQ） |
| 显示 | OLED，软件 I2C，**`SCL=PB9`、`SDA=PB8`（与手带端正好相反！）** |
| 执行器 | 2 路 PWM：`PA0`(TIM2_CH1)、`PA1`(TIM2_CH2)；方向脚 `PB12~PB15`；接 TB6612 |
| 反馈 | 编码器：左轮 TIM3(`PA6/PA7`)、右轮 TIM4(`PB6/PB7`)，四倍频计数 |
| 指示灯 | `PC13`、`PA5` ⚠️ **PA5 同时是 nRF 的 MOSI，被 LED_Init 抢过一次** |

> **必须记住的一件事**：`nRF24L01_API.c`、`OLED.c`、`led.c` 在**两个工程里各有一份同名文件，但里面的引脚定义不同**。
> Windows 文件系统不区分大小写，VS Code 的标签页也长得一样 —— 这是新手最容易"改了没反应"的地方。
> 从下一章起，我每次都会在代码块第一行标清来源路径。

## 二、整体架构：五层楼

```
┌──────────────────────────────────────────────────────────────────────┐
│ L4 应用层   遥控/User/main.c          小车/USER/main.c                │
│            手势映射 + 打包            解包 + 姿态映射 + PID + 4任务    │
├──────────────────────────────────────────────────────────────────────┤
│ L3 中间件   内联协议(0xA5…0x0D)  XOR校验    ├── FreeRTOS 内核          │
│            互补滤波(MPU6050.c 内)           │  tasks/queue/list/timers │
│            速度环 PID(main.c 内)            │  port(ARM_CM3)/heap_4    │
├──────────────────────────────────────────────────────────────────────┤
│ L2 驱动层   led  PWM  Motor  Encoder  OLED  OLED_Data                 │
│             nRF24L01_API  MyI2C  MPU6050  key  time4  SysTick          │
│             usart  delay  sys           ← 这些是"本项目自己写的"        │
├──────────────────────────────────────────────────────────────────────┤
│ L1 库函数   STM32F10x_FWLib（23 个外设驱动：gpio/tim/usart/rcc/…）      │
│            作用：把"写寄存器"包装成"填结构体 + 调函数"                  │
├──────────────────────────────────────────────────────────────────────┤
│ L0 底座     startup_stm32f10x_*.s（向量表/复位入口）                    │
│             system_stm32f10x.c（时钟树 → 72 MHz）                      │
│             stm32f10x.h（所有寄存器的名字）  core_cm3（内核）           │
│             stm32f10x_it.c（异常/中断入口）                            │
└──────────────────────────────────────────────────────────────────────┘
                              ▲ 再往下就是硬件：芯片、电机、屏幕、无线模块
```

### 每层的职责，用一句人话讲

| 层 | 职责 | 什么时候你会改它 |
|---|---|---|
| **L0 底座** | 芯片上电后**第一段执行的代码**：填向量表 → 调 `SystemInit()` 把 8 MHz 晶振倍频到 72 MHz → 跳进 `main()` | 几乎不改，但**必须看懂一次**（第 1 章），否则永远不知道为什么"忘了开时钟外设就不动" |
| **L1 库函数** | 官方固件库。每个外设一套 `XXX_Init()/XXX_Cmd()` | 不改，只查：想确认某个参数有什么可选项时翻它的 `.h` |
| **L2 驱动层** | 本项目作者写的"把某个硬件变成几个函数"：`Motor_SetPWM()`、`Encoder_Get()`、`OLED_ShowString()` | **你最常改的一层**（换引脚、加显示行、调 PWM 频率） |
| **L3 中间件** | 跟具体硬件无关的"算法与调度"：协议打包/解包、互补滤波、PID、FreeRTOS | 调参、改进算法都在这层 |
| **L4 应用层** | 决定"什么时候调用谁"：任务循环、主循环、状态机 | 加功能先看这层 |

### 为什么这个工程要分这么多层（也是你以后自己写代码该照抄的结构）

- **换硬件只动 L2**：比如把 OLED 从 PB8/PB9 换到 PB10/PB11，只改 `OLED.c` 里 3 行，L3/L4 一行不动。
- **换算法只动 L3**：把互补滤波换成卡尔曼滤波，`main.c` 里 `MPU6050_GetAngle()` 的调用完全不用改。
- **换流程只动 L4**：把 `while(1)` 改成 FreeRTOS 任务，是因为 L3 的 PID、协议都被封装成了函数，可以随便搬。

## 三、一次完整的"抬手 → 轮子转"（8 跳数据流）

这一节是全套教程的**主线剧情**，后面每一章都是在这条链上摘下一环来讲。

| 跳 | 发生什么 | 代码位置（实测行号） |
|:--:|---|---|
| ① | **读传感器**：I2C 连读 14 字节 → 加速度 ax/ay/az + 陀螺 gx/gy/gz | `遥控\APP\MPU6050.c` `MPU6050_GetData()` |
| ② | **算角度**：加速度算"绝对倾角"，陀螺积分算"变化量"，两者用 α=0.95 互补融合 → `pitch/roll` | `遥控\APP\MPU6050.c` 第 89–137 行 |
| ③ | **变手势**：`pitch>15°`→前进，`<-15°`→后退，`roll>15°`→左，`<-15°`→右，否则停 | `遥控\User\main.c` 第 62–73 行 `Gesture_Map()` |
| ④ | **打包**：`[0xA5][0x09][pitch 4B][roll 4B][gesture 1B][XOR][0x0D]` = 13 字节，补 0 到 32 字节 | `遥控\User\main.c` 第 75–93 行 `Protocol_Pack()` |
| ⑤ | **发无线**：写 TX FIFO → CE 拉高 → 等 IRQ 变低（发送完成） | `遥控\APP\nRF24L01_API.c` `NRF24L01_SendData()` |
| ⑥ | **收无线 + 解包**：读 32 字节 → 逐字段校验 → 限幅 ±80° → 加互斥量写入全局变量 | `FreeRTOS小车\USER\main.c` 第 182–208 行 `task_rx()` / 第 42–55 行 `Protocol_Unpack()` |
| ⑦ | **变目标速度**：pitch→前后速度 `speed_x`（去 10° 死区），roll→转向分量 `speed_y`（去 15° 死区）；`targetL=speed_x+speed_y`、`targetR=speed_x-speed_y` | 同文件 第 230–259 行 |
| ⑧ | **闭环 + 驱动**：编码器测实际转速 → PID 算 PWM → 限幅/起转补偿 → `Motor_SetPWM()` → H 桥 → 轮子 → 编码器…回到 ⑧ | 同文件 第 261–304 行 + `Encoder.c` + `Motor.c` + `PWM.c` |

> **一句话记住整条链**：`姿态 → 角度 → 手势/速度 → 帧 → 空中 → 帧 → 左右轮速 → PWM → 轮子 → 编码器 → 回到 PID`。
> 学完之后，你应该能在纸上默画出这 8 跳，并说出每一跳在哪个文件。

**三条硬依赖**（违反就会听不懂）：
1. **第 4 章（OLED）必须在第 8 章之前** —— 后面所有调试都靠屏幕看数字，没有屏幕你没法自测。
2. **第 7 章（编码器）必须在第 14 章（PID）之前** —— PID 的"反馈量"就是编码器读数。
