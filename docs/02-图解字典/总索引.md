## 三、答辩串讲主线（一分钟把八阶段串成一句话）

> 手带上 MPU6050 测出 pitch/roll（五）→ 超过 15° 判成手势（六）→ 装进 0xA5/0x0D 的帧（一）→ 用 nRF24L01 隔空发（四）→ 小车端收包、五道校验后解包（三）→ 目标速度做差速分配（八）→ 速度环 PID 用编码器反馈算 PWM（七）→ TB6612 驱动电机（二）→ 三个 FreeRTOS 任务并行跑（进阶）。

## 四、看图习惯（建议照做）

1. **先找“谁是谁”**：图里每个框都是实物或芯片，左边通常是“大脑”，右边通常是“干活的”。
2. **再看“线”**：实线＝真实连线，虚线＝可选/调试/反馈，箭头方向＝数据流向。
3. **遇到菱形**：那是“判断”，导游解说里一定会写“什么情况走哪边”。
4. **遇到字母**：翻本图下方的词典，不要跳过去。
5. **对照代码**：每篇文档末尾都有「代码对照表」，点进去就是带逐行注释的源码（`annotated/` 目录）。
