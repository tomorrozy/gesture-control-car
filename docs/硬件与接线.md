## 二、小车端（FreeRTOS · STM32F103ZE）

启动文件为 `startup_stm32f10x_hd.s`，对应高容量芯片（开发板为 STM32F103ZE）。

### 电机与编码器

| 功能 | 信号 | 引脚 | 模式 / 外设 | 代码位置 |
|---|---|---|---|---|
| 左电机方向 | IN1 | **PB12** | 推挽输出 | `HARDWARE/LED/Motor.c` |
| 左电机方向 | IN2 | **PB13** | 推挽输出 | 同上 |
| 右电机方向 | IN3 | **PB14** | 推挽输出 | 同上 |
| 右电机方向 | IN4 | **PB15** | 推挽输出 | 同上 |
| 左电机 PWM | PWM_A | **PA0** | TIM2_CH1，复用推挽 | `HARDWARE/LED/PWM.c` |
| 右电机 PWM | PWM_B | **PA1** | TIM2_CH2，复用推挽 | 同上 |
| 左编码器 | A / B 相 | **PA6 / PA7** | TIM3 编码器模式 TI12，上拉输入 | `HARDWARE/LED/Encoder.c` |
| 右编码器 | A / B 相 | **PB6 / PB7** | TIM4 编码器模式 TI12，上拉输入 | 同上 |

PWM 频率：`72 MHz / 36 / 100 = 20 kHz`（`PSC = 35`，`ARR = 99`），占空比 `0~100`。

### 无线与显示

| 模块 | 信号 | 引脚 | 模式 | 说明 |
|---|---|---|---|---|
| nRF24L01 | CSN | **PA2** | 推挽输出 | 软件 SPI |
| nRF24L01 | CE | **PA3** | 推挽输出 | |
| nRF24L01 | SCK | **PA4** | 推挽输出 | |
| nRF24L01 | MOSI | **PA5** | 推挽输出 | ⚠️ 与 LED1 复用，见下 |
| nRF24L01 | MISO | **PB0** | 上拉输入 | |
| nRF24L01 | IRQ | **PB1** | 上拉输入 | |
| OLED | SCL | **PB9** | 开漏输出 | ⚠️ 与手柄端**相反** |
| OLED | SDA | **PB8** | 开漏输出 | |
| 串口1 | TX / RX | **PA9 / PA10** | 复用推挽 / 浮空输入 | 115200 8N1 |
| LED | LED0 | **PC13** | 推挽输出 | |
| LED | LED1 | **PA5** | 推挽输出 | ⚠️ 与 nRF MOSI 冲突 |

> ⚠️ **已知引脚冲突**：小车端 `LED_Init()` 把 **PA5** 配成推挽输出，而 nRF24L01 的 **MOSI 也是 PA5**。
> `main()` 里 `NRF24L01_Init()` 在 `LED_Init()` 之后执行，所以最终是无线模块生效，LED1 实际不可用
> （SPI 通信时它会被高频翻转）。如果你要真正用 LED1，请改到别的引脚。

## 三、供电注意事项

- **nRF24L01 必须 3.3 V**，接 5 V 会烧毁；模块电源脚建议并联 **10 µF** 钽电容，否则上电握手偶发失败。
- 电机与主控建议**分开供电**，电机启动瞬间的电流跌落会导致单片机复位。
- H 桥和主控要**共地**。
- OLED、MPU6050 也是 3.3 V 器件，注意电平匹配。
