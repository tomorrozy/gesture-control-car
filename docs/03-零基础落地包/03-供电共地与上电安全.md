# 03 供电共地与上电安全（第一次上电必读）

> [!summary] 这一页解决什么问题
> **PDF 硬性要求 1「独立供电（电池 + 降压模块，禁止 USB 供电）」是全套材料里唯一「完全没碰过」的一条。**
> 库里关于供电的信息是**散落**的（`二阶段 综合答卷`、`四阶段 综合答卷`、`接线总图与总表`、`12 模拟面试题库 第三轮` 里都有片段），
> 但**没有一篇把「电从哪来、怎么分路、怎么共地、第一次上电按什么顺序」讲完**。
> 这一篇把它补全，并给出**可打印的逐点电压核对表**。
>
> ★ **配套**：本文负责「上电前 + 第一次上电」；[[硬件实测清单]] 负责「11 步实测 + 17 项参数回填」，两篇一起用。

## 一、三条铁律（违反任何一条都会浪费一整晚）

| # | 铁律 | 违反的后果 |
|:--:|---|---|
| 1 | ★★ **电机由电池供，MCU 由降压模块供；USB 只用于下载和调试** | PDF 硬性要求 1 不达标；电机启动瞬间把 USB 电压拉塌 → 复位 |
| 2 | ★★ **所有 GND 必须连在一起**（STM32、TB6612、电池、编码器、HC-05、OLED、MPU6050） | 串口乱码 / 收不到 / 传感器读数乱 / 下载失败 |
| 3 | ★★ **12V 绝不进任何 3.3V 引脚**；接线**先断电池，改完线再上电** | 烧 MCU、烧传感器，芯片不可逆损坏 |

## 二、电源树（本项目的正确拓扑）

```text
                ┌──────────────┐
   3S 电池 ────┤ 电源开关 3A  ├─── 保险丝 5A ─┬─────────────────────────┐
   11.1V/12V   └──────────────┘               │                         │
   (≥20C)                                     │                         │
                                     ┌────────▼────────┐      ┌─────────▼──────────┐
                                     │  TB6612  VM     │      │  LM2596 #1 → 5.0V  │
                                     │  (电机电源)      │      │  (逻辑电源)         │
                                     └───┬─────────┬───┘      └─────────┬──────────┘
                                         │         │                  │
                                   AO1/AO2     BO1/BO2          5V 母线（逻辑）
                                         │         │                  │
                                    左电机      右电机      ┌─────────┼──────────┬─────────┐
                                    (+编码器供电 3.3/5V)    │         │          │         │
                                                      手带端板   小车端板   HC-05×2   OLED×2
                                                      5V脚       5V脚      VCC       VCC
                                                          │         │
                                                    板载LDO出3.3V → MCU 内核 / 传感器
```

> [!warning] ★ 三条「别这么接」
> 1. **不要把电机接到降压模块后面** —— 电机电流 1~3A，LM2596 会掉压/过热，表现是「电机一转，屏幕重启」。
> 2. **不要把两块板的 3.3V 输出连在一起** —— 两个 LDO 硬连会互相灌电流（库内一阶段任务 2 已明确警告）。
> 3. **不要用杜邦线走电机电流** —— 接触电阻大、会打火；电机线必须焊、≥ 0.5mm²（约 20AWG）。

## 三、电流预算（★ 一定要自己实测回填）

> 下面「典型值」是量级参考，**实际值必须用万用表测**并填进 [[硬件实测清单]] 的「第三部分」。

| 支路 | 器件 | 典型 / 峰值 | 怎么测 |
|---|---|---|---|
| 逻辑 | STM32F103C8T6 | 约 30~50 mA | 串在 5V 支路量 |
| 逻辑 | OLED ×2 | 约 10~20 mA/个 | — |
| 逻辑 | HC-05 ×2 | 约 20~40 mA（发射瞬间更高） | ★ 掉线时优先量这个 |
| 逻辑 | MPU6050 | 约 4 mA | — |
| 逻辑 | 编码器 ×2（霍尔） | 约 10~20 mA/个 | — |
| **电机** | JGB37-520 12V 1:30 ×2 | 空载约 0.2~0.3 A/个；**启动/换向/堵转可达 1~3 A/个** | ★ 串万用表在 VM 支路，换向瞬间看跳变 |
| 合计 | 逻辑 ≈ **150 mA**（建议降压模块留 1A 余量） | | |
| 合计 | 电机 ≈ **峰值 4~6 A**（★ 电池必须能供） | | |

> ★ **电池选型反推**：峰值 5A ÷ 容量 = 需要的 C 数。
> 1500mAh（1.5Ah）电池要 3.3C 以上 → **买 ≥ 20C 的航模电池几乎必然够**。
> ⚠️ **9V 方电池、单节 18650 直供都不行**（电流能力不足 → 换向瞬间复位）。

## 四、共地与走线规则（8 条）

| # | 规则 | 为什么 |
|:--:|---|---|
| 1 | ★★ **星型接地**：电池负极 → **一个点** → 再分别到 TB6612 / 降压模块 / MCU / 编码器 / HC-05 | 避免电机大电流在 GND 上产生压差，污染传感器参考 |
| 2 | ★★ **电机线（M+/M-）与信号线分开走**，不要平行贴在一起 | 减少电磁干扰（阶段 3 原理篇提到赛场上干扰很强） |
| 3 | ★ **电源线用粗线**（红=正 黑=负），信号线用细杜邦线 | 大电流走细线会压降+发热 |
| 4 | ★ **电池正负极反接保护**：焊之前反复确认；最好加防反接二极管或插头做防呆 | 反接 = 瞬间烧驱动/板子 |
| 5 | **编码器供电按模块要求**（3.3V 或 5V），★ 接错会烧编码器 | 有的编码器只要 3.3V |
| 6 | **HC-05 用 5V 供电**（本项目文档一致口径），VCC 并 **100µF + 0.1µF** | 掉线的头号原因是电源塌陷 |
| 7 | **电池端并 470µF~1000µF 电解 + 0.1µF 陶瓷** | 吸收电机换向的电流冲击 |
| 8 | **所有插头/焊点拉一下确认牢固**，整机装好后**再拉一次** | 杜邦线松动是「时好时坏」类故障的元凶 |

## 五、★ TB6612 的 VCC 到底接几伏（库里有两套说法）

| 文档 | 说法 |
|---|---|
| `二阶段\任务1\阶段二 任务1 PWM开环调速与正反转.md` | 「VM 接 12V，**VCC 接 5V**」 |
| `七阶段\完整工程代码\README_编译前必读 七阶段.md` | 「VM→12V，**VCC→5V**」 |
| `接线总图\接线总图与总表.md` | 「降压模块 **3.3V** → MCU 3.3V、**TB6612 VCC**、STBY」 |
| `接线\接线全过程 总图与分步.md` | 「VM 接电池、**VCC 接 3.3V**、STBY 接 3.3V」 |

> [!warning] ★ 这是一处**真实的文档冲突**（详见 [[补充建议 零基础落地缺口清单]] 第 2 节）
> **两种接法在本项目里通常都能转**（模块实际输入门限偏低），但**从电气规范上**：
> - TB6612 的输入高电平门限跟随 VCC（VCC=5V 时手册门限约 0.7×VCC ≈ 3.5V），
>   而 STM32 输出只有 3.3V → **属于临界，可能偶发识别不到高电平**。
> - **VCC 与 MCU 同电平（3.3V）最稳妥**，同时 3.3V 也是 STBY 常使能的电平。
>
> ★ **建议**：**VCC 接 3.3V**；若你已经接 5V 且换向/使能都正常，可以不动，
> 但**把这条记进实测记录**（答辩时是一个能讲出「为什么」的细节）。

## 六、★ 上电顺序（六步，不许跳）

> ★ 目的：**每一步只新增一个变量**。这样任何异常都必然是「刚加的那一步」引起的。
> 这与库里「每阶段只新增一个变量」的教学思路一致。

| 步 | 做什么 | 期望现象 | 不对就停在这里 |
|:--:|---|---|---|
| **0** | **万用表通断档**：量 VM↔GND、5V↔GND **不短路** | 不蜂鸣 | 蜂鸣 → ★ **绝对不要上电**，先查焊点搭锡 |
| **1** | 电池 → 开关 → 降压模块，**空载**调出 5.00V | 4.9~5.1V | 调不出 → 模块坏/输入超范围 |
| **2** | 只给**两块板**供 5V（不接驱动、不接电机、不接蓝牙） | 板子电源灯亮；下载程序后 OLED/串口有输出 | 板子发热 → 立刻断电 |
| **3** | 接 TB6612（VM 接电池、VCC 接 3.3V、**先不接电机**） | 万用表量 STBY = 3.3V | STBY 不为高 → 电机永远不会转 |
| **4** | 接电机（**两轮悬空**！垫起来），烧阶段 2 程序 | 给 PWM 能转、能换向 | 见 [[硬件实测清单]] 第 2~5 步 |
| **5** | 接 MPU6050 / OLED（先读 `WHO_AM_I` = 0x68） | 读数正常 | 0x00/0xFF → 查 I2C 引脚与供电 |
| **6** | **最后**接两块 HC-05，两端上电，先小车端后手带端 | LED 慢闪/常亮；OLED 显示 `RX:OK` | 一直快闪 → 蓝牙没配对 |

> [!danger] 悬空是纪律，不是建议
> 从阶段 2 开始，**每次上电前先把两轮垫起来**。
> 特别是阶段 8：**「同号性」没验证过就开始跑 PID，一上电小车会直接冲出去**（正反馈）。

## 八、安全红线（10 条）

| # | 红线 |
|:--:|---|
| 1 | ★★ 两轮**悬空**后再上电跑程序 |
| 2 | ★★ 锂电池**不过放**（单节 < 3.0V 就充）、**不用力摔/穿刺**、**充电时人不要离开** |
| 3 | ★★ **改线前先关开关/断电池** |
| 4 | ★ 万用表**先选对档位**（电压档量电压，通断档量通断）；电流档要**串进回路**，别并联 |
| 5 | ★ 12V 与 3.3V 线**用不同颜色**，接头不裸露 |
| 6 | ★ 电机线**焊好 + 热缩管**，不要用胶带缠 |
| 7 | ★ 第一次给电机上电，**手指放在开关上** |
| 8 | ★ 别用手去捏转动的轮子（轮子会突然启动） |
| 9 | ★ 逻辑电源与电机电源**分别有开关**更好；至少电机侧有保险 |
| 10 | ★ 板子/芯片**发烫立刻断电**，不要「再试一次看看」 |

## 九、电源类故障速查

| 现象 | 最可能的原因 | 第一步怎么验证 |
|---|---|---|
| ★ 电机一转就复位 / 重启 | **电池电压塌陷**（电流能力不足或线细） | 示波器/万用表看换向瞬间的 VM 跌落 |
| ★ 电机一转蓝牙就掉线 | 逻辑电源被电机拉塌 | 给 HC-05 **单独供 5V** 试；并 100µF 电容 |
| 电机不转，PWM 和方向都对 | **STBY 没接高** / VM 没接电池 | 量 STBY 电压；量 VM 对 GND |
| 上电什么都没反应 | 开关/接插件接触不良 | 从电池往后面逐点量（照第七节表） |
| 串口乱码 / 收不到 | **没共地** 或波特率不一致 | 补 GND；核对两端波特率 |
| 传感器读数乱跳 | 地线干扰 / 电机线并行走线 | 改星型接地；电机线与信号线分开 |
| 下载失败、提示连不上芯片 | 供电不足 / SWD 被程序占用 | 单独给板子 5V；BOOT0=1 后用 ST-LINK Utility 擦除 |
| 电池很快就没电 | 电机堵转/底盘阻力大 | 手推车看是否顺滑；查万向轮高度 |
