## 二、Keil MDK 安装（第 1 步）

| 步 | 操作 | ★ 注意 |
|:--:|---|---|
| 1 | 双击 `Keil5 MDK\Keil5 MDK\MDK524a.EXE` | 建议**右键 → 以管理员身份运行** |
| 2 | 一路 Next，安装路径**保持默认** `C:\Keil_v5` | ★ **不要装到中文路径**，也不要装进本库目录 |
| 3 | 弹出设备包安装界面时，**先 Skip / 取消** | 稍后用手动 `.pack`（第 3 步）更可控 |
| 4 | 装完打开 Keil，`Pack Installer` 图标能点开 | 到这一步只算「装了编译器」 |

### ★ 关于 License（一定会遇到，先知道结论）

| 情况 | 现象 | 怎么办 |
|---|---|---|
| 未注册（MDK-Lite） | 编译到最后可能报 **代码大小超限**（`code size limit exceeded`） | ① 先看 Build Output 里的 **Code = ? KB**；② 本库工程已开 MicroLIB + Level 1 优化，**多数阶段能压到限制内**；③ 仍超限就把优化等级调到 `-O2/-O3` 再试；④ 正规做法是用学校/单位授权，或按 Keil 提示申请 **Arm 免费非商业 Community 授权** |

> 📌 **判断方法**：编译成功后看 Build Output 最后一行
> ```
> Program Size: Code=xxxxx RO-data=xxxx RW-data=xxx ZI-data=xxxx
> ```
> `Code + RO-data` 才是占用 Flash 的部分。**把这一行记下来**，答辩时也是有用的数据。

## 三、器件包（第 2 步，★ 不装就「找不到器件」）

**方法 A（推荐）**：双击
`Keil5 MDK\Keil5 MDK\支持包\Keil.STM32F1xx_DFP.2.2.0.pack`

**方法 B**：Keil → `Pack Installer` → `File → Import` → 选同一个 `.pack`

**验证**：Keil 里 `Project → Options for Target → Device`，搜索框输入 `STM32F103C8` 能选出来。

> 库里还带了 F0/F4/L0/L1/L4/W1 的包，本项目**只需要 F1**。

## 四、ST-Link 驱动（第 3 步）

```text
① 先不插下载器，运行：
   工具软件\工具软件\STLINK驱动\STLink\USBDriver\dpinst_amd64.exe   （64 位系统）
   （32 位系统用 dpinst_x86.exe）
② 插上 ST-Link，设备管理器应出现 STLink 相关设备
③ 若显示「未知设备」：右键更新驱动 → 手动指向
   工具软件\工具软件\STLINK驱动\STLink\USBDriver\
④ 若提示「需要升级固件」：运行同目录下的 ST-LinkUpgrade.exe
```

**验证**：打开 `STM32 ST-LINK Utility`（第 5 步装的）→ `Target → Connect`，能显示 `Device: STM32F103C8`。

## 五、CH340 驱动（第 4 步）

```text
运行：工具软件\工具软件\USB转串口CH340驱动\CH341SER.EXE → 安装

```

## 六、Keil 工程打开后的「固定配置」核对

本库 18 个工程的配置**已经配好了**（见 [[Keil 工程搭建说明]]），你只需**核对**这几项：

| 项 | 应该是什么 | 在哪看 |
|---|---|---|
| 器件 | STM32F103C8 | Options → Device |
| IRAM / IROM | 0x5000(20KB) / 0x10000(64KB) | Options → Target |
| 宏定义 | `USE_STDPERIPH_DRIVER` | Options → C/C++ → Define |
| **MicroLIB** | ★ **勾选** | Options → Target |
| 生成 HEX | 勾选 | Options → Output |
| Include Paths | `Keil 公共库\Start` / `Library` / `User` + 本阶段源码目录 | Options → C/C++ |
| **下载器** | **ST-Link Debugger** | Options → Debug |
| ★ **Reset and Run** | ★ **勾选**（否则烧完要手动复位才跑） | Options → Utilities → Settings → Flash Download |

> ⚠️ **两个新手必踩的工程设置坑**：
> 1. **`stm32f10x_it.c` 千万别加进工程**（`Keil 公共库\User\` 里有这个文件）——
>    它会和各阶段自己写的 `USART1_IRQHandler` **重复定义**。
> 2. **`.h` 文件不用加进工程**，但要**放在磁盘目录里**（IncludePath 能找到就行）。

## 七、一次「从零到点灯」的通路验证（★ 强烈建议先做）

> 目的：**把「工具链问题」和「项目代码问题」分开**。
> 不要一上来就编译八阶段的工程，否则报错你不知道该怪谁。

> [!warning] ★★ 先知道这件事：**二~七阶段的工程不能直接编过**
> 它们**缺 2~3 个公共模块**（`OLED.c/h`、`OLED_Font.h`、`Key.c/h`、`Delay.c/h`），
> 既不在阶段目录里，也没加进 Keil 工程 → **F7 会直接报 `cannot open source input file "OLED.h"`**。
>
> ✅ **只有「一阶段」和「八阶段」是拿来就能编的**。
> ★ 所以下面这条路用**一阶段**做验证，是对的；补文件的方法见 **[[06 各阶段编译前补文件清单]]**。

```text
① Keil 打开：一阶段\Keil工程\一阶段-任务1-串口双向\Project.uvprojx
   （权威库 D: 版路径是：01 一阶段\Keil工程\一阶段-任务1-串口双向\Project.uvprojx）
② F7（Build）→ 应显示 0 Error, 0 Warning
③ 接 ST-Link（SWCLK/SWDIO/GND/3.3V 四根线）
④ F8（Download）→ Build Output 出现 "Programming Done. Verify OK."
⑤ 板子接 USB-TTL，打开串口助手（波特率见该阶段文档）→ 能看到板子发来的字符
```

**五步全过 = 工具链没问题**，后面所有问题都可以直接怀疑接线或代码。
（★ 一阶段工程**自包含**，不需要补任何公共文件；这正是它适合做首次验证的原因。）

## 八、常见安装/下载报错速查（15 条）

| # | 现象 | 原因 | 处理 |
|:--:|---|---|---|
| 1 | `Device not found` / 器件列表里没有 STM32F103 | 没装 DFP 器件包 | 装 `Keil.STM32F1xx_DFP.2.2.0.pack` |
| 2 | `Error: Flash Download failed - Target DLL has been cancelled` | ① 下载器没连上 ② 芯片被读保护/锁了 ③ 没选 Flash 算法 | 先用 ST-LINK Utility 连接；能连上就 `Target→Option Bytes` 解保护 |
| 3 | 找不到 ST-Link（`No ST-LINK detected`） | 驱动没装 / 线序错 / 固件旧 | 装驱动；检查 SWCLK↔SWCLK、SWDIO↔SWDIO；跑 ST-LinkUpgrade |
| 4 | 下载成功但**程序不跑**，手动按复位才跑 | 没勾 **Reset and Run** | Options → Utilities → Settings → Flash Download → 勾选 |
| 5 | `cannot open source input file "stm32f10x.h"` | IncludePath 失效 | Options → C/C++ → Include Paths 补 `Keil 公共库\Start`（★ 别单独挪库文件夹） |
| 5b | ★★ `cannot open source input file "OLED.h"` / `"Key.h"` / `"Delay.h"` | **二~七阶段工程本来就缺这些公共文件** | 见 **[[06 各阶段编译前补文件清单]]**（含精确复制来源 + 加入工程的方法） |
| 6 | `Symbol xxx multiply defined` | 把 `stm32f10x_it.c` 也编进去了 | 从工程里移除它 |
| 7 | `USART1_IRQHandler multiply defined` | `Serial.c` 与 `Frame.c` 都定义了（一阶段任务 1~4 的已知冲突） | 只保留一个（见 [[从零上手教程]] 的说明） |
| 8 | **code size limit exceeded** | MDK-Lite 32KB 限制 | 见本文第二节 License |
| 9 | 编译报一堆中文乱码/警告 | 源文件编码不一致 | 用 `UltraCodingSwitch.exe` 统一为 UTF-8 无 BOM |
| 10 | 板子插上电脑没反应 | ① USB 线是**只充电线** ② 板子没供电 | 换一根**数据线** |
| 11 | CH340 装不上（黄色感叹号） | 驱动签名 | 关驱动强制签名 / 手动指定 `DRIVER\CH341SER.INF` |
| 12 | 串口助手打不开 COM 口（`拒绝访问`） | 被别的软件占用（Keil 的串口窗口、VOFA+） | 关掉其他软件再开 |
| 13 | 串口收到乱码 | **波特率不一致** / 没共地 | 两端波特率一致；**补一根 GND** |
| 14 | 下载时提示 `Could not stop Cortex-M device` | ① 程序里禁了 SWD ② 复位电路问题 | 按住复位键点下载；或把 BOOT0=1 后上电再用 ST-LINK Utility 擦除 |
| 15 | 两块板**一块能下载一块不能** | 下载器线序/板子坏 | 交叉验证：把能下载的板子换线试 |

## 九、VOFA+（★ 库里没带，要自己下）

| 步 | 做什么 |
|:--:|---|
| 1 | 官网下载 VOFA+ 客户端（搜索 `VOFA+ 官网` 即可） |
| 2 | 打开 → 选 **串口** → 选 CH340 的 COM 口 → 波特率与代码一致 |
