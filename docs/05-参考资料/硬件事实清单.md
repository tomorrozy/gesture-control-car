## 一、题目原文：八个阶段的任务

| 阶段 | 名称 | 任务原文要点 |
| :--- | :--- | :--- |
| 第一阶段 | 双机通信基础 | 任务1：STM32 与电脑串口双向通信（按键发字符串如 "Hello"，电脑发数据显示在 OLED）；任务2：两块 STM32 用 UART 互连（TX-RX 交叉、共地），一块发一块收并显示；任务3：自定义协议（**帧头 0xA5、帧尾 0x0D**，格式建议 `[0xA5][长度][数据内容][校验码][0x0D]`）；任务4：在任务3基础上改用 **UART + DMA** 传输 |
| 第二阶段 | 电机驱动基础 | 任务1：PWM 开环调速与正反转；任务2：读电机反馈（编码器），换算成输出轴**转速**（rad/s 或 °/s）与**位置**（rad 或 °）；任务3：按键切换模式（**关控模式** PWM=0 自由停止 / **速度模式** 匀速转动）并用 LED 指示；任务4：OLED 实时显示当前模式、实际转速、实际位置 |
| 第三阶段 | 双机通信控制电机 | 任务1：一块板发指令，另一块板接收并控制电机**正反转**；任务2：指令能**切换目标速度**，电机端能响应 |
| 第四阶段 | 蓝牙无线通信 | 任务1：用**蓝牙模块替换有线 UART**，实现无线双机通信；任务2：通信稳定、指令能正确接收并执行。（题目允许 HC-05 蓝牙 **或** nRF24L01；本工程实际用 **nRF24L01 2.4GHz**） |
| 第五阶段 | MPU6050 与姿态解算 | 任务1：MPU6050 **I2C 通信**正常，读到原始数据；任务2：姿态解算（低年级可用加速度计直接算角，高年级**必须**互补滤波或卡尔曼滤波）；任务3：角度稳定、无剧烈跳动（如何解决 **yaw 零漂**） |
| 第六阶段 | 手势控制单个电机 | 任务1：手势映射正确（**正转 / 反转 / 停止**），有线连接；任务2：手带端通过无线发送手势指令，电机端响应 |
| 第七阶段 | 速度闭环 PID | 任务1：固定目标速度的**速度闭环 PID**，用 **VOFA+** 打印“当前转速 vs 目标转速”波形整定参数；任务2：目标速度**可调**（按键或串口），理解 P/I/D 影响；任务3：**手势控速**（IMU 姿态角映射为目标速度，实时跟随、方向一致、倾斜越多转速越高；屏幕上显示**目标转速、实际转速、手势、模式**） |
| 第八阶段 | 手势控制小车 | 任务1：控制四个电机实现**前进、后退、左转、右转**（其实两个驱动轮做**差速转向**就能实现）；任务2：小车运动**平稳、响应及时** |
| 进阶拓展 | 选做（无阶段限制，额外加分） | ① 用 **FreeRTOS** 管理按键扫描 / PID 计算 / 通信 / 显示等任务；② 用 **CAN 通信**驱动支持 CAN 的电机；③ 上位机（VOFA+ 或自写）实时显示姿态角、电机速度，并**在线修改 PID 参数** |

## 二、手带端（`遥控` 工程）事实

- 单片机：STM32F103（C8T6 最小系统板）。
- **nRF24L01 无线**（软件 SPI）：`CSN = PA0`、`CE = PA1`、`SCK = PA2`、`MOSI = PA3`、`MISO = PA4`、`IRQ = PA5`。
- **MPU6050**（软件 I2C）：`SCL = PB6`、`SDA = PB7`（`MyI2C.c` 里有行尾注释写 PB10/PB11，是模板遗留，实际是 PB6/PB7）。
- **OLED**（SSD1306，软件 I2C）：`SCL = PB8`、`SDA = PB9`。
- **DHT22 温湿度**（单总线）：`PA12`。
- **按键**（1ms 扫描，长按阈值 `presstime = 500ms`）：`KEY1 = PB12`、`KEY2 = PB13`、`KEY3 = PB14`、`KEY4 = PB15`、`KEY5 = PA8`。
- **LED**：`LED0 = PC13`、`LED8 = PA7`（`led.c` 只初始化这两个；头文件里 LED1=PB0、LED2~LED7=PA1~PA6 只是定义）。
- **TIM4**：1ms 更新中断，`TIM4_IRQHandler` 写在 `User/main.c` 里，中断里累加 `Time_ms/Time_ms2/esp_ms` 并调用 `prekey()` 扫描按键。
- **主流程**：`main()` → `SysTick_Init(72)`、`LED_Init`、`Key_Init`、`OLED_Init`、`TIM4_Init(1000-1, 72-1)`、`MPU6050_Init`、`MPU6050_CalibrateGyro(200/1000)`、`NRF24L01_Init` → `while(NRF24L01_Check())` 显示 “ON” → `NRF24L01_TX_Mode_Init(TX_ADDR1)` → `while(1) OLED_1menu()`。
- **姿态解算**（`MPU6050.c`）：`MPU6050_GetAngle(&angle)` 输出 `Pitch/Roll`（互补滤波，ALPHA 加权陀螺积分 + 加速度角，`LOOP_TIME = 0.01s`，限幅 ±90°；无磁力计所以 Yaw 恒 0）。
- **手势映射**（`User/main.c` 的 `Gesture_Map`，阈值 15°）：`pitch > +15` → 前进 `GESTURE_FWD=1`；`pitch < -15` → 后退 `=2`；`roll > +15` → 左转 `=3`；`roll < -15` → 右转 `=4`；都不满足 → 停止 `=5`（`GESTURE_NONE=0` 是无手势初值）。**先判 pitch 再判 roll**。
- **协议组帧**（`Protocol_Pack`）：`out[0]=0xA5`、`out[1]=9`、`out[2..5]=pitch(4字节 float)`、`out[6..9]=roll`、`out[10]=gesture`、`out[11]=异或校验(XOR out[1..10])`、`out[12]=0x0D`；发送时 `NRF24L01_SendData(tx_frame, 32)` **固定发 32 字节**（与 13 字节帧长不一致，已在注释里标 NOTE）。
- **发送周期**：每 100ms（`if(Time_ms > 100)`）发一帧；OLED 显示角度 + 手势编号 `G:`。
- **串口**：`遥控` 工程**没有** USART 初始化代码（早期阶段用串口，最终版本改成了无线 nRF24L01）。

## 三、小车端（`FreeRTOS小车` 工程）事实

- 单片机：STM32F103ZE（大容量）。
- **nRF24L01 无线**（软件 SPI）：`CSN = PA2`、`CE = PA3`、`SCK = PA4`、`MOSI = PA5`、`MISO = PB0`、`IRQ = PB1`；多通道接收（通道 0 地址 `0x11...`、通道 1 地址 `0x22...`）。
- **TB6612 驱动**（原理图核实）：`PWMA = PA0 (TIM2_CH1)`、`PWMB = PA1 (TIM2_CH2)`；左轮 `AIN2 = PB12`、`AIN1 = PB13`；右轮 `BIN1 = PB14`、`BIN2 = PB15`；`VM = 12V`、`VCC = 3.3V`、`STBY = 3.3V`（常高）；输出 `AO1/AO2` 接左电机、`BO1/BO2` 接右电机。
- **PWM**：TIM2，`PSC = 36-1`、`ARR = 100-1` → 72MHz/36/100 = **20kHz**；CCR 0~100 对应 0~100% 占空比。
- **编码器**：左 `TIM3_CH1/CH2 = PA6/PA7`；右 `TIM4_CH1/CH2 = PB6/PB7`；`TIM_EncoderMode_TI12`（四倍频）；TIM4 的 CH2 用下降沿（右轮镜像反相）；`Encoder_Get` 读 CNT 后清零。
- **LED**：`LED0 = PC13`、`LED1 = PA5`（⚠️ PA5 同时被 nRF 的 MOSI 使用，代码里存在冲突，已标 NOTE）。
- **串口**：`USART1`，`PA9 = TX`、`PA10 = RX`，**115200-8N1**；`printf` 重定向到 USART1（`fputc`）；接收中断按 `0x0D 0x0A` 结尾组帧（`USART_RX_STA` 状态机）。用于调试打印和 **VOFA+ 波形**。
- **FreeRTOS**：静态创建（`configSUPPORT_STATIC_ALLOCATION`），`main()` 里：`NVIC_PriorityGroup_4` → `delay_init()` → `uart_init(115200)` → `OLED_Init/LED_Init/Motor_Init/Encoder_Init/NRF24L01_Init` → `while(NRF24L01_Check())` 显示“无线模块错误” → 显示“无线模块正常” → `NRF24L01_RX_MultiChannel_Init()` → `PID_Init(&pid_left, 2.0f, 1.50f, 0.0f)`、`PID_Init(&pid_right, 2.0f, 1.50f, 0.0f)` → `xSemaphoreCreateMutexStatic(&xMutexBuf)` → `xTaskCreateStatic(start_task, "start", 128, NULL, 1, ...)` → `vTaskStartScheduler()`。
- **任务**：`start_task`（优先级 1）创建 3 个任务后 `vTaskDelete` 自己；`task_rx`（优先级 3，栈 256 字）20ms 轮询 `NRF24L01_RxPacket_Multi` → `Protocol_Unpack` → pitch/roll 限幅 ±80 → 互斥量保护写 `g_pitch/g_roll/g_gesture`；`task_ctrl`（优先级 2，栈 256）20ms：死区 10°、转向阈值 15°、线性映射到 0~100、`REVERSE_TURN=1` 反向、差速 `targetL/targetR`、编码器换算 `g_act = enc / 52.0f / 0.02f / 9.27666f * 5.0f`、`PID_Calc`、最小 PWM 30 死区补偿、限幅 ±100、`Motor_SetPWM`；`task_disp`（优先级 1，栈 256）50ms：状态字符串（停止/前进/后退/原地左右转/前进左右转…）、`SCREEN_FLIP=1` 倒装屏、OLED 中文显示、`sprintf`。
- **协议解包**（`Protocol_Unpack`）：`len == 13`、`buf[0] == 0xA5`、`buf[1] == 9`、`buf[12] == 0x0D`、`XOR(buf[1..10]) == buf[11]`；`memcpy` 把 4 字节小端 float 还原成 pitch/roll。
- **编码器换算式**：52 = 13 线 × 4 倍频；减速比 9.27666；采样周期 0.02s；`* 5.0f` 是经验缩放（不是物理量纲）。
- **未实现**：CAN 通信（工程里没有 CAN 代码）；HC-05 蓝牙（改用 nRF24L01）；VOFA+ 在线改 PID（只做了打印）。
