## 📡 本章前置知识点雷达

> [!info] 预习指南：在啃代码之前，先认识这些“硬核名词”
> 本章围绕以下 5 个概念展开。

| 知识点名称 | 一句话通俗解释 | 在本章代码中的角色 |
| :--- | :--- | :--- |
| **PWM 占空比** | 快速开关电源，开得越久平均功率越大。 | `PWM.c`，CCR 0~100 |
| **时基 PSC/ARR** | 把 72 MHz 心跳分频、计数，得到目标频率。 | `PWM.c:27–33` |
| **H 桥方向控制** | 两根方向脚决定电流方向。 | `Motor.c:29–61` |
| **编码器四倍频** | A/B 相每个边沿都计数。 | `Encoder.c:45` |
| **减速比 1:13** | 电机转 13 圈，输出轴转 1 圈。 | 换算速度时要除以 13 |

> [!success] 硬件已核对（来源：嘉立创 Board1 原理图，2026-10-24）
> TB6612 六线：`PWMA=PA0`、`PWMB=PA1`、`AIN1=PB13`、`AIN2=PB12`、`BIN1=PB14`、`BIN2=PB15`；`STBY=3.3V`（常使能，代码不驱动）。
> 编码器：左 `PA6/PA7`、右 `PB6/PB7`，供电 **3.3 V**（H2/H3 排针）。
> 详见 [[00_嘉立创硬件解析_原理图与软硬映射]]。
> ⚠️ 仍待实物：编码器 A/B **线序**（计数符号反了就交换 A/B）、LED 高低有效（图纸未见 LED，代码按高电平写）、编码器**线数**（52=4×线数 → 13，仍是反推值）。

## 三、逐行精讲

### 3.1 PWM 初始化 · 时钟与引脚（PWM.c 8–21 行）

```c
void PWM_Init(void)
{
	GPIO_InitTypeDef GPIO_InitStructure;
	RCC_APB1PeriphClockCmd(RCC_APB1Periph_TIM2, ENABLE);
	RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOA, ENABLE);

	GPIO_InitStructure.GPIO_Mode = GPIO_Mode_AF_PP;
	GPIO_InitStructure.GPIO_Pin = GPIO_Pin_0 | GPIO_Pin_1;
	GPIO_InitStructure.GPIO_Speed = GPIO_Speed_50MHz;
	GPIO_Init(GPIOA, &GPIO_InitStructure);
```

【第 8 行】函数定义：无参数，上电调用一次。
【第 10 行】声明 GPIO 配置结构体。
【第 12 行】开 TIM2 时钟（TIM2 挂 APB1）。
【第 13 行】开 GPIOA 时钟。
【第 17 行】`AF_PP`：复用推挽，引脚交给定时器。
【第 18 行】`GPIO_Pin_0 | GPIO_Pin_1`：即 PA0 与 PA1。
【第 19 行】输出速度档位 `50MHz`。
【第 20 行】写入配置。

> [!abstract] 人话翻译
> 先给定时器和 GPIOA 通电，再把 PA0/PA1 切成“定时器专用”。漏开时钟的现象是“程序在跑、引脚没波形”，编译器不报错。

### 3.2 PWM 初始化 · 时基（PWM.c 24–33 行）

```c
	TIM_InternalClockConfig(TIM2);
	TIM_TimeBaseInitTypeDef TIM_TimeBaseInitStructure;
	TIM_TimeBaseInitStructure.TIM_ClockDivision = TIM_CKD_DIV1;
	TIM_TimeBaseInitStructure.TIM_CounterMode = TIM_CounterMode_Up;
	TIM_TimeBaseInitStructure.TIM_Period = 100 - 1;
	TIM_TimeBaseInitStructure.TIM_Prescaler = 36 - 1;
	TIM_TimeBaseInitStructure.TIM_RepetitionCounter = 0;
	TIM_TimeBaseInit(TIM2, &TIM_TimeBaseInitStructure);
```

【第 24 行】选内部时钟源（源码注释：不调用默认也是内部时钟）。
【第 27 行】声明时基结构体。
【第 28 行】滤波时钟不分频（不影响时基单元的计数频率）。
【第 29 行】向上计数。
【第 30 行】`100 - 1`：ARR=99，计 0~99 共 100 个数。
【第 31 行】`36 - 1`：PSC=35，实际分频 36（写值 = 实际值 − 1）。
【第 32 行】重复计数器仅高级定时器使用。
【第 33 行】写入时基。

> [!abstract] 人话翻译
> 频率 = 72 MHz ÷ 36 ÷ 100 = 20 kHz。20 kHz 超出人耳敏感区，电机不啸叫；CCR 0~100 就是 0~100% 占空比。
> **72 MHz 的出处**：`system_stm32f10x.c` 里 `SYSCLK_FREQ_72MHz` 生效、`SetSysClockTo72()` 配 `RCC_CFGR_PLLMULL9`，配合 `stm32f10x.h` 的 `HSE_VALUE = 8000000`。本段代码只给了 PSC/ARR，**主频不是本文件写的**。

### 3.3 PWM 初始化 · 输出比较（PWM.c 35–48 行）

```c
	TIM_OCInitTypeDef TIM_OCInitStructure;
	TIM_OCStructInit(&TIM_OCInitStructure);
	TIM_OCInitStructure.TIM_OCMode = TIM_OCMode_PWM1;
	TIM_OCInitStructure.TIM_OCPolarity = TIM_OCPolarity_High;
	TIM_OCInitStructure.TIM_OutputState = TIM_OutputState_Enable;
	TIM_OCInitStructure.TIM_Pulse = 0;
	TIM_OC1Init(TIM2, &TIM_OCInitStructure);
	TIM_OC2Init(TIM2, &TIM_OCInitStructure);
	TIM_Cmd(TIM2, ENABLE);
}
```

【第 36 行】声明输出比较结构体。
【第 37 行】`TIM_OCStructInit`：先填默认值，避免未赋值成员是随机数。
【第 40 行】`TIM_OCMode_PWM1`：PWM 模式 1。
【第 41 行】`TIM_OCPolarity_High`：高电平有效。
【第 42 行】`TIM_OutputState_Enable`：输出使能。
【第 43 行】`TIM_Pulse = 0`：初始 CCR=0（0% 占空比，上电不转）。
【第 44–45 行】通道 1、2 都初始化。
【第 48 行】`TIM_Cmd`：启动定时器（总闸）。

> [!abstract] 人话翻译
> 三件事：模式、极性、初值。最后 `TIM_Cmd` 是总开关，和串口的 `USART_Cmd` 一个道理。

### 3.4 改占空比（PWM.c 58–73 行）

```c
void PWM_SetCompare1(uint16_t Compare)
{
	TIM_SetCompare1(TIM2, Compare);
}

void PWM_SetCompare2(uint16_t Compare)
{
	TIM_SetCompare2(TIM2, Compare);
}
```

【第 58 行】设置通道 1 的 CCR。
【第 60 行】写 CCR1（对应 PA0）。
【第 70 行】设置通道 2 的 CCR。
【第 72 行】写 CCR2（对应 PA1）。

> [!abstract] 人话翻译
> 占空比 = CCR/(ARR+1) = CCR/100（源码 55–56 行注释写的就是 `Duty = CCR1 / (ARR + 1)`）。函数名里的 1/2 是定时器通道，不直接等于左右轮，左右由 `Motor.c` 决定。

### 3.5 电机初始化（Motor.c 9–21 行）

```c
void Motor_Init(void)
{
	RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOB, ENABLE);
	GPIO_InitTypeDef GPIO_InitStructure;
	GPIO_InitStructure.GPIO_Mode = GPIO_Mode_Out_PP;
	GPIO_InitStructure.GPIO_Pin = GPIO_Pin_12 | GPIO_Pin_13 | GPIO_Pin_14 | GPIO_Pin_15;
	GPIO_InitStructure.GPIO_Speed = GPIO_Speed_50MHz;
	GPIO_Init(GPIOB, &GPIO_InitStructure);
	PWM_Init();
}
```

【第 9 行】函数定义。
【第 12 行】开 GPIOB 时钟（方向脚在此）。
【第 14 行】声明结构体。
【第 15 行】普通推挽输出。
【第 16 行】PB12~PB15 四根方向脚。
【第 18 行】写入配置。
【第 20 行】顺带初始化 PWM。

> [!abstract] 人话翻译
> 每个电机需要“2 根方向脚 + 1 路 PWM”。这里先配方向脚，再调 PWM 初始化，所以外部只需调用 `Motor_Init`。

### 3.6 左轮输出（Motor.c 29–45 行）

```c
void Motor_SetPWM(uint8_t n, int8_t PWM)
{
	if (n == 1)
	{
		if (PWM >= 0)
		{
			GPIO_SetBits(GPIOB, GPIO_Pin_12);
			GPIO_ResetBits(GPIOB, GPIO_Pin_13);
			PWM_SetCompare1(PWM);
		}
		else
		{
			GPIO_ResetBits(GPIOB, GPIO_Pin_12);
			GPIO_SetBits(GPIOB, GPIO_Pin_13);
			PWM_SetCompare1(-PWM);
		}
	}
```

【第 29 行】`Motor_SetPWM(uint8_t n, int8_t PWM)`：`n` 选电机，PWM 是**8 位有符号**（±100 有效）。
【第 31 行】左轮分支。
【第 33 行】非负视为正转。
【第 35–36 行】PB12 高、PB13 低。
【第 37 行】占空比 = `PWM`。
【第 41–43 行】反转时两脚互换，CCR 取 `-PWM`。
【第 45 行】分支结束。

> [!abstract] 人话翻译
> 先定方向、再给占空比。反过来会在换向瞬间产生反向电流尖峰，驱动芯片容易发烫。

### 3.8.5 输入捕获与滤波（Encoder.c 33–51 行）

```c
	TIM_ICInitTypeDef TIM_ICInitStructure;
	TIM_ICStructInit(&TIM_ICInitStructure);
	TIM_ICInitStructure.TIM_Channel = TIM_Channel_1;
	TIM_ICInitStructure.TIM_ICFilter = 0xF;
	TIM_ICInit(TIM3, &TIM_ICInitStructure);
	TIM_ICInitStructure.TIM_Channel = TIM_Channel_2;
	TIM_ICInitStructure.TIM_ICFilter = 0xF;
	TIM_ICInit(TIM3, &TIM_ICInitStructure);
	TIM_EncoderInterfaceConfig(TIM3, TIM_EncoderMode_TI12, TIM_ICPolarity_Rising, TIM_ICPolarity_Rising);
	TIM_Cmd(TIM3, ENABLE);
```

【第 33 行】声明输入捕获结构体。
【第 34 行】先填默认值，避免未赋值成员是随机数。
【第 37 行】配置通道 1。
【第 38 行】`TIM_ICFilter = 0xF`：最大滤波档，滤掉电机换向毛刺。
【第 39 行】写入通道 1 配置。
【第 40 行】配置通道 2。
【第 41 行】同样是 `0xF` 滤波。
【第 42 行】写入通道 2 配置。
【第 45 行】`TIM_EncoderMode_TI12`：A/B 两相都计数（四倍频）；两个 `Rising` 表示都不反相。
【第 51 行】启动 TIM3。

> [!warning] 源码注释里的两个关键约束（原始第 47–49 行）
> ① 编码器模式下 `Rising/Falling` **不再表示“上升沿/下降沿”，而是表示“是否反相”**；
> ② `TIM_EncoderInterfaceConfig` **必须在 `TIM_ICInit` 之后调用**，否则输入捕获的配置会覆盖它。

> [!abstract] 人话翻译
> 先给两个通道配滤波（`0xF` 最大档，抗毛刺），再告诉定时器“这是编码器接口、两相都计数”。顺序反了会被覆盖——这是源码注释专门警告过的坑。

### 3.10 读增量（Encoder.c 99–116 行）

```c
int16_t Encoder_Get(uint8_t n)
{
	int16_t Temp;
	if (n == 1)
	{
		Temp = TIM_GetCounter(TIM3);
		TIM_SetCounter(TIM3, 0);
		return Temp;
	}
	else if (n == 2)
	{
		Temp = TIM_GetCounter(TIM4);
		TIM_SetCounter(TIM4, 0);
		return Temp;
	}
	return 0;
}
```

【第 99 行】返回“自上次调用以来的增量”。
【第 102 行】`int16_t Temp`：有符号，反转时为负。
【第 103–107 行】左轮：读 CNT 后立刻清零。
【第 109–113 行】右轮同样。
【第 115 行】非法参数返回 0。

> [!abstract] 人话翻译
> 读一次就清零，所以拿到的是“这 20 ms 转了多少”。代价是位置信息被丢掉，想测位置要自己累加。

### 3.11 增量 → 速度（main.c 261–266 行）

```c
        encL = Encoder_Get(1);
        encR = Encoder_Get(2);

        /* 将 0~20 映射为 0~100 */
        g_act_left  = (encL / 52.0f / 0.02f / 9.27666f) * 5.0f;
        g_act_right = (encR / 52.0f / 0.02f / 9.27666f) * 5.0f;
```

【第 261–262 行】各读一次增量。
【第 265–266 行】÷52（每电机圈计数）÷0.02（20 ms 周期）÷9.27666 ×5。

> [!warning] 用 1:13 核对（算术推导）
> 物理正确式：`输出轴 rev/s = enc ÷ 52 ÷ 0.02 ÷ 13`。
> 代码除的是 **9.27666** → 结果偏大 `13 ÷ 9.27666 ≈ 1.40`，即**反馈被高估约 40%**。
> 输出轴每圈计数 = 52 × 13 = **676**。修正：两处改 `13.0f`，然后重调 Ki。
> ⚠️ 该推导依赖两个前提：线数=13（反推值，待确认）、减速比=13（你已确认）。

> [!abstract] 人话翻译
> 量纲对、系数错。反馈尺子偏大，PID 收敛到的真实速度就偏低，且参数被迫加大。
