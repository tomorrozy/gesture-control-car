## 📡 本章前置知识点雷达

> [!info] 预习指南：在啃代码之前，先认识这些“硬核名词”
> 本章围绕以下 5 个概念展开。

| 知识点名称 | 一句话通俗解释 | 在本章代码中的角色 |
| :--- | :--- | :--- |
| **软件 SPI** | 用普通 GPIO 手动敲时钟，一字节 8 拍。 | `SPI_RW` |
| **寄存器访问** | 片选拉低 → 发地址 → 收发数据 → 拉高。 | `Write_Reg / Read_Reg` |
| **射频参数一致** | 两端信道、速率、地址必须一样。 | `RF_CH=40`、`RF_SETUP=0x0F` |
| **自动 ACK** | 接收端自动回执，发送端等不到就重发。 | `EN_AA`、`SETUP_RETR` |
| **模块自检** | 写一段再读回，判断模块在不在。 | `NRF24L01_Check` |

> [!warning] 硬件待确认（防幻觉）
> 代码只给 MCU 侧引脚；nRF 模块供电电压、是否带功放、天线形式、去耦电容，代码里都没有。嘉立创工程文件当前只剩空表，**不猜。**

## 三、逐行精讲

### 3.1 两端引脚定义（小车 3–8 行 / 遥控 4–9 行）

```c
/* 小车端 */
#define NRF_CSN   PAout(2)
#define NRF_CE    PAout(3)
#define NRF_SCK   PAout(4)
#define NRF_MOSI  PAout(5)
#define NRF_MISO  PBin(0)
#define NRF_IRQ   PBin(1)

/* 遥控端 */
#define NRF_CSN   PAout(0)
#define NRF_CE    PAout(1)
#define NRF_SCK   PAout(2)
#define NRF_MOSI  PAout(3)
#define NRF_MISO  PAin(4)
#define NRF_IRQ   PAin(5)
```

【小车 3–4 行】CSN=PA2、CE=PA3。
【小车 5–6 行】SCK=PA4、MOSI=PA5。
【小车 7–8 行】MISO=PB0、IRQ=PB1（在 GPIOB）。
【遥控 4–5 行】CSN=PA0、CE=PA1。
【遥控 6–7 行】SCK=PA2、MOSI=PA3。
【遥控 8–9 行】MISO=PA4、IRQ=PA5。

> [!abstract] 人话翻译
> 两端同名文件、引脚完全不同。小车端 MISO/IRQ 在 GPIOB，初始化必须同时开 GPIOA/GPIOB；遥控端全在 GPIOA。

### 3.2 软件 SPI 前半（小车 38–55 行）

```c
uchar SPI_RW(uchar byte)
{
    uchar bit_ctr;
    uchar receive = 0;

    for(bit_ctr = 0; bit_ctr < 8; bit_ctr++)
    {
        if(byte & 0x80)
            NRF_MOSI = 1;
        else
            NRF_MOSI = 0;

        byte <<= 1;
        NRF_SCK = 1;
```

【第 38 行】发一字节、同时收一字节。
【第 40–41 行】循环变量与接收缓存。
【第 43 行】循环 8 次。
【第 46–49 行】取最高位放 MOSI（MSB 先发）。
【第 51 行】左移顶上来的下一位。
【第 54 行】SCK 拉高（从机采样）。

> [!abstract] 人话翻译
> SPI 是同步串行：先摆数据再抬时钟，上升沿就是从机采样时刻。

### 3.3 软件 SPI 后半（小车 57–66 行）

```c
        receive <<= 1;
        if(NRF_MISO)
            receive |= 0x01;

        NRF_SCK = 0;
    }

    return receive;
}
```

【第 57 行】接收缓存左移，腾最低位。
【第 58–59 行】读 MISO，为 1 置最低位。
【第 62 行】SCK 拉低（从机换下一位）。
【第 63 行】循环结束。
【第 65 行】返回收到的字节（写寄存器时就是 STATUS）。

> [!abstract] 人话翻译
> 全双工：发送和接收同一时刻完成。上升沿采样、下降沿换数据，即 SPI Mode 0。

### 3.4 读写寄存器（小车 68–89 行）

```c
uchar NRF24L01_Write_Reg(uchar reg, uchar value)
{
    uchar status;
    NRF_CSN = 0;
    status = SPI_RW(reg);
    SPI_RW(value);
    NRF_CSN = 1;
    return status;
}
uchar NRF24L01_Read_Reg(uchar reg)
{
    uchar value;
    NRF_CSN = 0;
    SPI_RW(reg);
    value = SPI_RW(NOP);
    NRF_CSN = 1;
    return value;
}
```

【第 68 行】写寄存器函数。
【第 72 行】CSN 拉低选中模块。
【第 73 行】发“写命令+地址”，同时收回 STATUS。
【第 74 行】发数据。
【第 75 行】CSN 拉高，事务结束。
【第 79 行】读寄存器函数。
【第 84 行】发“读命令+地址”。
【第 85 行】发 NOP 把数据挤出来。
【第 86 行】结束事务。

> [!abstract] 人话翻译
> 一次寄存器访问=片选拉低、发命令字、收发数据、片选拉高；读时靠 NOP 占位字节把从机数据挤出来。

### 3.5 模块自检（小车 115–140 行）

```c
uchar NRF24L01_Check(void)
{
    uchar check_buf[5] = {0xAA, 0xBB, 0xCC, 0xDD, 0xEE};
    uchar read_buf[5] = {0};
    uchar i;

    NRF_CE = 0;
    NRF_CSN = 1;
    DelayMs(10);

    NRF24L01_Write_Buf(nRF_WRITE_REG + TX_ADDR, check_buf, 5);
    DelayMs(10);
    NRF24L01_Read_Buf(nRF_READ_REG + TX_ADDR, read_buf, 5);

    for(i = 0; i < 5; i++)
    {
        if(read_buf[i] != check_buf[i])
            return 1;
    }
    return 0;
}
```

【第 115 行】自检函数。
【第 117 行】5 字节测试数据。
【第 118 行】读回缓存。
【第 119 行】循环变量。
【第 121–123 行】CE 低、CSN 高、等 10 ms。
【第 126 行】写入 TX_ADDR。
【第 127 行】再等 10 ms。
【第 130 行】读回。
【第 133–137 行】逐字节比较，不一致返回 1。
【第 139 行】全一致返回 0。

> [!abstract] 人话翻译
> 返回值反着来：**1=失败、0=成功**，所以调用方写 `while(Check())`。它只验证 SPI 四线与供电，**不验证射频**。

### 3.6 接收端管道与射频参数（小车 221–256 行）

```c
    NRF24L01_Write_Buf(nRF_WRITE_REG + RX_ADDR_P0, (uchar*)TX_ADDR1, RX_ADR_WIDTH);
    NRF24L01_Write_Reg(nRF_WRITE_REG + RX_PW_P0, RX_PLOAD_WIDTH);
    NRF24L01_Write_Buf(nRF_WRITE_REG + RX_ADDR_P1, (uchar*)TX_ADDR2, RX_ADR_WIDTH);
    NRF24L01_Write_Reg(nRF_WRITE_REG + RX_PW_P1, RX_PLOAD_WIDTH);
    NRF24L01_Write_Reg(nRF_WRITE_REG + EN_AA, 0x03);
    NRF24L01_Write_Reg(nRF_WRITE_REG + EN_RXADDR, 0x03);
    NRF24L01_Write_Reg(nRF_WRITE_REG + SETUP_RETR, 0x1A);
    NRF24L01_Write_Reg(nRF_WRITE_REG + RF_CH, 40);
    NRF24L01_Write_Reg(nRF_WRITE_REG + RF_SETUP, 0x0F);
    NRF24L01_Write_Reg(nRF_WRITE_REG + CONFIG, 0x0F);
    NRF24L01_Write_Reg(FLUSH_RX, 0xFF);
    NRF_CE = 1;
```

【第 226 行】管道 0 地址 `0x11×5`。
【第 227 行】管道 0 载荷 32 字节。
【第 230–231 行】管道 1 地址 `0x22×5`、载荷 32。
【第 234 行】`EN_AA=0x03`：两条管道都开自动应答。
【第 237 行】`EN_RXADDR=0x03`：两条管道都使能。
【第 240 行】`SETUP_RETR=0x1A`：见下方纠错。
【第 243 行】`RF_CH=40`：2440 MHz。
【第 246 行】`RF_SETUP=0x0F`：2 Mbps、0 dBm。
【第 249 行】`CONFIG=0x0F`：上电 + CRC16 + 接收模式。
【第 252 行】清 RX FIFO。
【第 254 行】CE 拉高开始监听。

> [!warning] 手册事实纠错
> `SETUP_RETR=0x1A` 注释写“500 µs、重发 10 次”**是错的**：高 4 位重发次数=1，低 4 位间隔档=10 → 250+250×10=**2750 µs**。

> [!abstract] 人话翻译
> 接收端只做三件事：定管道地址、开自动应答、把信道/速率/CRC 设成与发送端一致，最后 CE 拉高开始听。

### 3.7 ⚠️ 发送端 ACK 地址错配（小车 183–219 行；遥控同函数在 196–232 行）

```c
void NRF24L01_TX_Mode_Init(uchar *tx_addr)
{
    NRF_CE = 0;
    NRF24L01_Write_Buf(nRF_WRITE_REG + TX_ADDR, tx_addr, TX_ADR_WIDTH);
    NRF24L01_Write_Buf(nRF_WRITE_REG + RX_ADDR_P0, (uchar*)RX_ADDR, RX_ADR_WIDTH);
    ...
    NRF24L01_Write_Reg(nRF_WRITE_REG + CONFIG, 0x0E);
    NRF_CE = 1;
}
```

【第 183 行】发送模式初始化。
【第 185 行】CE 先拉低。
【第 188 行】写 TX_ADDR（实参 `TX_ADDR1`=`0x11×5`）。
【第 191 行】写 RX_ADDR_P0=`RX_ADDR`（=`0xAA×5`）——问题在这。
【第 212 行】`CONFIG=0x0E`：上电 + CRC16 + 发送模式。
【第 217 行】CE 拉高。

> [!warning] 推理：为什么每包都“失败”
> 手册规则：接收端沿**管道地址**回 ACK；发送端只有 `RX_ADDR_P0` 等于该地址才收得到。
> 你：ACK 发往 `0x11…`，发送端在 `0xAA…` 等 → 收不到 → 重发到上限 → 返回 `0x10`。数据仍到接收端，所以车能控。
> 修法：第 191 行改成 `(uchar*)tx_addr`。

> [!abstract] 人话翻译
> `TX_ADDR` 决定包飞去哪，`RX_ADDR_P0` 决定在哪等回执；两者不一致就是“每包白重发”。

### 3.8 接收端收包（小车 263–282 行）

```c
uchar NRF24L01_RxPacket_Multi(uchar *rxbuf, uchar *channel)
{
    uchar state;
    state = NRF24L01_Read_Reg(STATUS);
    if(state & RX_OK)
    {
        *channel = (state & RX_P_NO_MASK) >> 1;
        NRF24L01_Read_Buf(RD_RX_PLOAD, rxbuf, RX_PLOAD_WIDTH);
        return 0;
    }
    return 1;
}
```

【第 263 行】收包函数。
【第 268 行】读 STATUS。
【第 271 行】判断 `state & RX_OK`（宏=0x40；手册名 RX_DR）是否置位。
【第 274 行】取管道号（bit3:1）。
【第 277 行】读 32 字节。
【第 278 行】返回成功。
【第 281 行】没数据返回 1。

> [!warning] 缺失项
> 这里**没有** `FLUSH_RX`、**没有**写 STATUS 清 `RX_OK`、**没有** CE 切换 → 标志一直挂着，靠解包失败兜底。

> [!abstract] 人话翻译
> 收包=看标志→取管道→读 FIFO；少清标志不会立刻坏，但分不清“真收到”与“标志还挂着”。

### 3.9 遥控端收包对照（279–309 行）

```c
    if(state & RX_OK)
    {
        *channel = (state & RX_P_NO_MASK) >> 1;
        NRF_CE = 0;
        NRF24L01_Read_Buf(RD_RX_PLOAD, rxbuf, RX_PLOAD_WIDTH);
        NRF24L01_Write_Reg(FLUSH_RX, 0xFF);
        NRF24L01_Write_Reg(nRF_WRITE_REG + STATUS, state);
        NRF_CE = 1;
        return 0;
    }
```

【第 292 行】CE 拉低暂停接收。
【第 295 行】读 payload。
【第 298 行】清 RX FIFO。
【第 301 行】写 STATUS 原值 → 写 1 清标志。
【第 303 行】CE 拉高恢复。
【第 305 行】返回成功。

> [!abstract] 人话翻译
> 这份是标准写法：读前暂停、读后清 FIFO、写状态清标志；把这三行抄到小车端即可去掉空读。

### 3.10 发包与发送应用层（小车 284–334 行）

```c
uchar NRF24L01_TxPacket(uchar *txbuf)
{
    uchar state;
    uint timeout = 0;
    NRF_CE = 0;
    NRF24L01_Write_Buf(WR_TX_PLOAD, txbuf, TX_PLOAD_WIDTH);
    NRF_CE = 1;
    DelayUs(10);
    timeout = 0;
    while(NRF_IRQ == 1)
    {
        timeout++;
        if(timeout > 50000) break;
    }
    state = NRF24L01_Read_Reg(STATUS);
    NRF24L01_Write_Reg(nRF_WRITE_REG + STATUS, state);
    if(state & MAX_TX) { NRF24L01_Write_Reg(FLUSH_TX, 0xFF); return 0x10; }
    if(state & TX_OK) { return 0x20; }
    return 0xFF;
}

void NRF24L01_SendData(uchar *data, uchar len)
{
    uchar send_buf[32] = {0};
    uchar i;
    for(i = 0; i < len && i < 32; i++) send_buf[i] = data[i];
    NRF24L01_TxPacket(send_buf);
}
```

【第 284 行】发包函数。
【第 286–287 行】`state`、`timeout` 声明。
【第 289 行】CE 拉低。
【第 292 行】写 32 字节进 TX FIFO。
【第 294 行】CE 拉高（发射脉冲）。
【第 295 行】保持约 10 µs。
【第 299–304 行】轮询 IRQ 变低，5 万次超时。
【第 307–308 行】读 STATUS 再写回（清标志）。
【第 310–313 行】最大重发 → 清 TX FIFO，返回 0x10。
【第 316–318 行】成功返回 0x20。
【第 326 行】应用层 32 字节缓冲。
【第 327 行】`uchar i;` 循环变量。
【第 330–331 行】双重限制拷贝。
【第 333 行】**返回值被直接丢弃**。

> [!abstract] 人话翻译
> 发包=装弹（写 FIFO）→扣扳机（CE 脉冲）→等回执（IRQ）→读结果。结果设计齐全（0x10/0x20），但应用层把它扔了。
