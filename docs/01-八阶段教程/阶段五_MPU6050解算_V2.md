## 三、逐行精讲

### 3.1 I2C 引脚层：写 SCL / 写 SDA（MyI2C.c 13–29 行）

```c
void MyI2C_W_SCL(uint8_t BitValue)
{
	GPIO_WriteBit(GPIOB, GPIO_Pin_6, (BitAction)BitValue);
	delay_us(10);
}

void MyI2C_W_SDA(uint8_t BitValue)
{
	GPIO_WriteBit(GPIOB, GPIO_Pin_7, (BitAction)BitValue);
	delay_us(10);
}
```

【第 13 行】写 SCL 函数。
【第 15 行】写 `GPIOB` 的 `Pin_6`（推导名 PB6）。
【第 16 行】写后等 10 µs，控制总线速率。
【第 25 行】写 SDA 函数。
【第 27 行】写 `GPIOB` 的 `Pin_7`（推导名 PB7）。
【第 28 行】同样等 10 µs。

> [!abstract] 人话翻译
> 这层只干两件事：设电平、等一会儿。每比特约 3 次操作 × 10 µs ≈ 30 µs，速率约 33 kHz，远低于 MPU 的 400 kHz 上限。

### 3.2 读 SDA 与引脚初始化（MyI2C.c 37–65 行）

```c
uint8_t MyI2C_R_SDA(void)
{
	uint8_t BitValue;
	BitValue = GPIO_ReadInputDataBit(GPIOB, GPIO_Pin_7);
	delay_us(10);
	return BitValue;
}
void MyI2C_Init(void)
{
	RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOB, ENABLE);
	GPIO_InitTypeDef GPIO_InitStructure;
	GPIO_InitStructure.GPIO_Mode = GPIO_Mode_Out_OD;
	GPIO_InitStructure.GPIO_Pin = GPIO_Pin_6 | GPIO_Pin_7;
	GPIO_InitStructure.GPIO_Speed = GPIO_Speed_50MHz;
	GPIO_Init(GPIOB, &GPIO_InitStructure);
	GPIO_SetBits(GPIOB, GPIO_Pin_6 | GPIO_Pin_7);
}
```

【第 37 行】读 SDA 函数。
【第 40 行】读 `Pin_7` 电平。
【第 41 行】读完延时保持节拍。
【第 51 行】初始化函数。
【第 54 行】开 GPIOB 时钟。
【第 58 行】`Out_OD`：开漏输出（I2C 必须）。
【第 59 行】两脚一起配。
【第 64 行】置高，释放总线。

> [!abstract] 人话翻译
> 开漏=只能拉低、不能强推高，高电平靠外部上拉；多设备挂一起不会互相灌电流。初始化最后必须置高，否则第一次通信起点不对。

### 3.3 起始与终止（MyI2C.c 74–92 行）

```c
void MyI2C_Start(void)
{
	MyI2C_W_SDA(1);
	MyI2C_W_SCL(1);
	MyI2C_W_SDA(0);
	MyI2C_W_SCL(0);
}
void MyI2C_Stop(void)
{
	MyI2C_W_SDA(0);
	MyI2C_W_SCL(1);
	MyI2C_W_SDA(1);
}
```

【第 74 行】起始信号。
【第 76–77 行】SDA、SCL 都置高。
【第 78 行】SCL 高时 SDA 降 = 起始。
【第 79 行】SCL 拉低占住总线。
【第 87 行】终止信号。
【第 89 行】SDA 拉低。
【第 90 行】SCL 拉高。
【第 91 行】SCL 高时 SDA 升 = 终止。

> [!abstract] 人话翻译
> I2C 只有两个“特殊时刻”：SCL 高时 SDA 下降=开始，上升=结束；其余时间 SDA 只能在 SCL 低时变。

### 3.4 发送一个字节（MyI2C.c 99–108 行）

```c
void MyI2C_SendByte(uint8_t Byte)
{
	uint8_t i;
	for (i = 0; i < 8; i ++)
	{
		MyI2C_W_SDA(Byte & (0x80 >> i));
		MyI2C_W_SCL(1);
		MyI2C_W_SCL(0);
	}
}
```

【第 99 行】发送字节函数。
【第 101 行】循环变量。
【第 102 行】循环 8 次。
【第 104 行】从最高位开始逐位放 SDA。
【第 105 行】SCL 拉高，从机采样。
【第 106 行】SCL 拉低准备下一位。

> [!abstract] 人话翻译
> MSB 先发。`Byte & (0x80>>i)` 结果只有 0 或非 0，写进 GPIO 就是低或高。

### 3.5 接收一个字节（MyI2C.c 115–127 行）

```c
uint8_t MyI2C_ReceiveByte(void)
{
	uint8_t i, Byte = 0x00;
	MyI2C_W_SDA(1);
	for (i = 0; i < 8; i ++)
	{
		MyI2C_W_SCL(1);
		if (MyI2C_R_SDA() == 1){Byte |= (0x80 >> i);}
		MyI2C_W_SCL(0);
	}
	return Byte;
}
```

【第 115 行】接收字节函数。
【第 117 行】`Byte` 必须初始化为 0。
【第 118 行】主机释放 SDA。
【第 119 行】循环 8 次。
【第 121 行】SCL 拉高，高电平期间读。
【第 122 行】读到 1 就置对应位。
【第 124 行】SCL 拉低，从机换下一位。
【第 126 行】返回整字节。

> [!abstract] 人话翻译
> 接收与发送镜像：发送在低电平改数据、接收在高电平读数据；读之前必须先释放 SDA。

### 3.6 ACK / NACK（MyI2C.c 134–154 行）

```c
void MyI2C_SendAck(uint8_t AckBit)
{
	MyI2C_W_SDA(AckBit);
	MyI2C_W_SCL(1);
	MyI2C_W_SCL(0);
}
uint8_t MyI2C_ReceiveAck(void)
{
	uint8_t AckBit;
	MyI2C_W_SDA(1);
	MyI2C_W_SCL(1);
	AckBit = MyI2C_R_SDA();
	MyI2C_W_SCL(0);
	return AckBit;
}
```

【第 134 行】发应答函数。
【第 136 行】应答位放上 SDA（0=ACK、1=NACK）。
【第 137–138 行】一个 SCL 脉冲。
【第 146 行】收应答函数。
【第 149 行】释放 SDA。
【第 150 行】SCL 拉高。
【第 151 行】读从机应答位。
【第 152 行】SCL 拉低。
【第 153 行】返回应答位。

> [!abstract] 人话翻译
> 每发一字节，接收方回一个 ACK；读多字节时中间回 ACK（继续）、最后一个回 NACK（够了）。

### 3.7 连续读 14 字节（MPU6050.c 18–39 行）

```c
void MPU6050_ReadMultiReg(uint8_t RegAddress, uint8_t *pData, uint8_t len)
{
	uint8_t i;
	MyI2C_Start();
	MyI2C_SendByte(MPU6050_ADDRESS);
	MyI2C_ReceiveAck();
	MyI2C_SendByte(RegAddress);
	MyI2C_ReceiveAck();
	MyI2C_Start();
	MyI2C_SendByte(MPU6050_ADDRESS | 0x01);
	MyI2C_ReceiveAck();
	for(i=0; i<len-1; i++)
	{
		pData[i] = MyI2C_ReceiveByte();
		MyI2C_SendAck(0);
	}
	pData[len-1] = MyI2C_ReceiveByte();
	MyI2C_SendAck(1);
	MyI2C_Stop();
}
```

【第 18 行】连读函数。
【第 21 行】起始。
【第 22 行】写地址 `0xD0`。
【第 23 行】收 ACK（未检查）。
【第 24 行】写寄存器号。
【第 27 行】重复起始（不释放总线）。
【第 28 行】读地址 `0xD1`。
【第 31–35 行】前 len−1 字节：读一个、回 ACK。
【第 36 行】最后一字节。
【第 37 行】回 NACK。
【第 38 行】停止释放总线。

> [!abstract] 人话翻译
> 标准读时序：写地址→写寄存器→重复起始→读地址→连续读；中间 ACK、最后 NACK，写反了芯片会提前停或总线卡住。

### 3.8 14 字节拼成 6 个 int16（MPU6050.c 41–53 行）

```c
void MPU6050_GetData(int16_t *AccX, int16_t *AccY, int16_t *AccZ,
						int16_t *GyroX, int16_t *GyroY, int16_t *GyroZ)
{
	uint8_t buf[14];
	MPU6050_ReadMultiReg(MPU6050_ACCEL_XOUT_H, buf, 14);
	*AccX = (buf[0]  << 8) | buf[1];
	*AccY = (buf[2]  << 8) | buf[3];
	*AccZ = (buf[4]  << 8) | buf[5];
	*GyroX= (buf[8]  << 8) | buf[9];
	*GyroY= (buf[10] << 8) | buf[11];
	*GyroZ= (buf[12] << 8) | buf[13];
}
```

【第 41 行】读 6 轴函数。
【第 44 行】14 字节缓冲（6 轴×2 + 温度×2）。
【第 45 行】从 `0x3B` 连读 14 字节。
【第 47–49 行】加速度三轴，高字节在前。
【第 50–52 行】陀螺三轴，跳过 `buf[6]/[7]` 温度。
【第 53 行】函数结束。

> [!abstract] 人话翻译
> 每轴两字节、高字节在前；温度跳过。`int16_t` 才保留负号，用无符号会把负值变成 6 万多。

```c
	roll = 0;

```

【第 55 行】初始化函数。
【第 57 行】先初始化 I2C。
【第 58 行】`PWR_MGMT_1=0x01`：解除睡眠、时钟选 PLL。
【第 59 行】`PWR_MGMT_2=0x00`：6 轴使能。
【第 60 行】`SMPLRT_DIV=0x09`：1 kHz/(1+9)=100 Hz。
【第 61 行】`CONFIG=0x06`：DLPF_CFG=6 → 约 5 Hz。
【第 62 行】`GYRO_CONFIG=0x18`：FS_SEL=3 → ±2000 °/s（16.4 LSB）。
【第 63 行】`ACCEL_CONFIG=0x18`：AFS_SEL=3 → ±16 g（2048 LSB）。
【第 64–65 行】清内部角度。

> [!abstract] 人话翻译
> 六个寄存器决定“采样多快、量程多大、滤多狠”。量程与代码里的 16.4/2048 必须成对，改一个不改另一个，角度会差几倍。

### 3.10 陀螺零偏校准（MPU6050.c 68–86 行）

```c
void MPU6050_CalibrateGyro(uint16_t samples)
{
	int16_t ax,ay,az,gx,gy,gz;
	int32_t sumX=0, sumY=0;
	uint16_t i;
	for(i=0; i<samples; i++)
	{
		MPU6050_GetData(&ax,&ay,&az,&gx,&gy,&gz);
		sumX += gx;
		sumY += gy;
		for(uint32_t j=0;j<5000;j++);
	}
	gyroX_offset = (float)sumX / samples;
	gyroY_offset = (float)sumY / samples;
	pitch = 0;
	roll = 0;
}
```

【第 68 行】校准函数，参数是采样次数。
【第 70 行】暂存 6 轴。
【第 71 行】32 位累加防溢出。
【第 74 行】循环采样。
【第 76 行】读一次。
【第 77–78 行】累加 gx、gy。
【第 79 行】空循环拉长间隔。
【第 82–83 行】求平均作零偏。
【第 84–85 行】校准后清零角度。

> [!abstract] 人话翻译
> 静止时陀螺理论输出 0、实际有几 LSB 偏差；把平均值记下来供扣除。校准时必须绝对静止，而且只校了 X/Y，Z 轴没校。

### 3.11 加速度算绝对角（MPU6050.c 89–101 行）

```c
static void GetAccelAngles(int16_t ax, int16_t ay, int16_t az, float *acc_pitch, float *acc_roll)
{
	float ax_g = (float)ax / ACCEL_SCALE_FACTOR;
	float ay_g = (float)ay / ACCEL_SCALE_FACTOR;
	float az_g = (float)az / ACCEL_SCALE_FACTOR;
    float sqrt_yz = sqrtf(ay_g*ay_g + az_g*az_g);
    *acc_pitch = atan2f(ax_g, sqrt_yz) * 57.2958f;
    float sqrt_xz = sqrtf(ax_g*ax_g + az_g*az_g);
    *acc_roll  = atan2f(-ay_g, sqrt_xz) * 57.2958f;
}
```

【第 89 行】函数：三轴加速度 → 两个角度。
【第 91–93 行】原始值 ÷2048 变成“几个 g”。
【第 96 行】`√(ay²+az²)`。
【第 97 行】`atan2(y=ax, x=√…)×57.2958` 变角度。
【第 99 行】`√(ax²+az²)`。
【第 100 行】`atan2(−ay, x)` 得横滚角（用 −ay 定正方向）。

> [!abstract] 人话翻译
> 加速度计感知重力方向，所以能算绝对倾角、但一动就抖。`atan2f(y, x)` 的参数顺序不能反，反了会得到互补角。

### 3.12 互补滤波（MPU6050.c 104–137 行）

```c
void MPU6050_GetAngle(MPU6050_Angle *angle)
{
	int16_t ax,ay,az,gx,gy,gz;
	float acc_pitch, acc_roll;
	float gx_deg, gy_deg;
    float cos_roll, sin_roll, cos_pitch;
	MPU6050_GetData(&ax,&ay,&az,&gx,&gy,&gz);
	GetAccelAngles(ax, ay, az, &acc_pitch, &acc_roll);
	gx_deg = (gx - gyroX_offset) / GYRO_SCALE_FACTOR;
	gy_deg = (gy - gyroY_offset) / GYRO_SCALE_FACTOR;
    cos_roll = cosf(roll * 3.14159f / 180.0f);
    sin_roll = sinf(roll * 3.14159f / 180.0f);
    cos_pitch = cosf(pitch * 3.14159f / 180.0f);
    float pitch_gyro = gy_deg + gx_deg * sin_roll * tanf(pitch * 3.14159f / 180.0f);
    float roll_gyro  = gx_deg * cos_roll - gy_deg * sin_roll;
    pitch = ALPHA * (pitch + pitch_gyro * LOOP_TIME) + (1 - ALPHA) * acc_pitch;
    roll  = ALPHA * (roll  + roll_gyro  * LOOP_TIME) + (1 - ALPHA) * acc_roll;
	if(pitch > 90) pitch=90; if(pitch < -90) pitch=-90;
	if(roll  > 90) roll=90;  if(roll  < -90) roll=-90;
	angle->Pitch = pitch;
	angle->Roll  = roll;
	angle->Yaw   = 0;
}
```

【第 104 行】取角度函数。
【第 111 行】读 6 轴。
【第 112 行】加速度算绝对角。
【第 114–115 行】减零偏、换 °/s。
【第 118–119 行】算 `cos(roll)`、`sin(roll)`。
【第 120 行】算 `cos_pitch`——**算了后面没用**（死代码，源码原样）。
【第 123 行】俯仰陀螺解耦（含 `tanf(pitch)`，±90° 附近发散）。
【第 124 行】横滚陀螺解耦。
【第 127–128 行】互补滤波：α 信陀螺、1−α 信加速度。
【第 131–132 行】限幅 ±90。
【第 134–136 行】写回结构体，Yaw 恒 0。

> [!abstract] 人话翻译
> 陀螺短期准、久了漂；加速度长期准、一动就抖。`0.95×陀螺积分 + 0.05×加速度角` 拼起两者优点；`LOOP_TIME=0.01f` 是“假设 10 ms 调用一次”的约定，错了滤波强度就变。

【第 169–172 行】`GetID`：读 `WHO_AM_I`（`MPU6050_Reg.h:26` = 0x75）。

> [!warning] 依赖关系
> `MPU6050_Init` 第 58–63 行正是靠 `WriteReg` 写那 6 个寄存器——所以 139–149 是必须讲的依赖。但 `ReadReg`/`GetID` 在本工程**从未被调用**。

> [!abstract] 人话翻译
> 写寄存器=起始+写地址+写寄存器号+写数据+停止；读单寄存器=写地址+写寄存器号+重复起始+读地址+读 1 字节+NACK。自检本应读 `WHO_AM_I` 看是否 0x68，但没人调。

### 3.14 主程序怎么用（遥控 main.c 99–107、134–144 行）

```c
	SysTick_Init(72);
	LED_Init();
	Key_Init();
	OLED_Init();
	TIM4_Init(1000-1,72-1); //定时1ms
	MPU6050_Init();
	MPU6050_CalibrateGyro(200);
	MPU6050_CalibrateGyro(1000);
...
	MPU6050_GetAngle(&angle);
	MPU6050_GetData(&AX, &AY, &AZ, &GX,& GY, &GZ);
...
    pitch = angle.Pitch * -1.0f;
    roll  = angle.Roll  * -1.0f;
...
    if (pitch >  80.0f) pitch =  80.0f;
    if (pitch < -80.0f) pitch = -80.0f;
```

【第 99 行】`SysTick_Init(72)`：`delay_us` 的基础。
【第 100–102 行】LED / 按键 / OLED 初始化。
【第 103 行】TIM4 1 ms 中断（`Time_ms`）。
【第 104 行】`MPU6050_Init()`。
【第 105–106 行】**连续两次校准**：200 次后 1000 次，第二次覆盖第一次。
【第 134 行】`GetAngle` 解算。
【第 135 行】再读一次原始值（仅显示）。
【第 138–139 行】整体 `× -1.0f` 适配安装方向。
【第 141–144 行】限幅 ±80，为手势映射留边界。

> [!abstract] 人话翻译
> 上电顺序：时基 → 外设 → 传感器初始化 → 校准（连做两次，第一次白做）→ 主循环每轮取角度、再取原始值显示；取反与限幅是装配补丁，不是算法。

## 四、硬件与现象对照

| 项目 | 代码给的 | 依据 |
|---|---|---|
| SCL / SDA | `GPIOB` Pin6 / Pin7（=PB6/PB7） | `MyI2C.c:15/27` |
| 8 位写地址 | 0xD0（7 位 0x68） | `MPU6050.c:7` |
| 起始寄存器 | 0x3B | `MPU6050_Reg.h:9` |
| 量程 | ±2000 °/s、±16 g | `:62–63` |
| 采样率/滤波 | 100 Hz / DLPF ≈5 Hz | `:60–61` |

> [!warning] 待确认（防幻觉）
> 模块 VCC、上拉阻值、AD0 电平、安装朝向，代码里都没有；嘉立创工程文件无法解析。**不猜。**

| 操作 | 现象 |
|---|---|
| 上电 | 遥控 OLED 显示两个整数角度 |
| 前倾 | pitch 变化，略有滞后 |
| 快速晃动 | 数字跳变（加速度仅 5% 权重） |
| 静止一分钟 | 缓慢漂一点但不会无限漂 |
| 旋转（yaw） | 没有输出（写死 0） |
| 模块没插 | 无报错，角度乱跳 |

> [!warning] `LOOP_TIME` 证据链（推导）
> 主循环每轮含：两次 14 字节 I2C 读（`GetAngle` 内一次 + `main.c:135` 一次）+ 整屏 OLED 刷新 + 每 100 ms 打包发送。软件 I2C 每次电平操作等 10 µs，整屏刷新最耗时。**“10 ms 一轮”只是假设**，必须用 `Time_ms` 实测；若实际远大于 10 ms，陀螺积分步长偏小、角度更依赖加速度、更抖。
